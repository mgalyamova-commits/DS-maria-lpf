# IWE совершенствование — журнал рассуждений

Ветка мета-уровня: работа над самой архитектурой IWE-системы (структура репо, роли файлов, правила агентов) — не про Марию как человека (это LPF-регламент), не про конкретный проект, а про инструмент, которым Мария и агенты пользуются. Ведёт — ветка IWE_Церен (мета-ветка IWE с 27.09.2026, отдельного чата «IWE совершенствование» нет).

Формат записи — «рабочая запись» по FPF (см. `FPF_подход_левенчук` в Google Drive, раздел 7): Entity of Concern / Bounded Context / Текущее утверждение / Intended Use / Основание. Цель — чтобы другой агент мог продолжить рассуждение по записи без устного восстановления (FPF, «коллективное мышление возникает, когда...»).

**Как вести этот файл (с 27.09.2026, Запись 9):** здесь — только открытые записи и короткая очередь. Закрытая запись уезжает дословно в архив месяца (`iwe-development/arhiv-log-<ГГГГ-ММ>.md`, пишется один раз; следующий перенос в том же месяце — новый файл с суффиксом `-2`, `-3`, готовый архив не перепечатывать), здесь от неё остаётся строка в индексе вместе с условием пересмотра. Нумерация сквозная, номера не переиспользуются. Пункт «Планируется» — 2–3 строки; подробности появляются в записи, когда задача взята в работу.

**С 14.10.2026 (Запись 32):** строки закрытых записей — в `iwe-development/log-index.md`, не здесь (читается по триггеру). Новая запись — пять полей FPF и строка Reopen, до 1,5 КБ; «Не проверено» — одной фразой в Основании. Таблицы blob sha, «Внедрено», «Ответ ветки» — в `docs/zhurnal/<дата>-<ветка>-<тема>.md`, в записи на них одна ссылка. Старые записи не переписываются.
