Этот файл — только указатель: сюда ничего не дописывать. Все ссылки вида «правки записываются в `docs/zhurnal-izmeneniy.md`» читать как «новой записью в `docs/zhurnal/`».

## Как записать

- Новый файл `docs/zhurnal/<ГГГГ-ММ-ДД>-<ветка>-<тема>.md`, латиницей, через дефисы. Существующие записи не править.
- Первая строка — заголовок: `# ДД.ММ.ГГГГ — <Ветка>: <что изменилось>`. По заголовкам папка читается как оглавление.
- Дальше не больше десяти строк: какие файлы изменены и прежняя версия (blob sha), одной строкой — зачем, ссылка на место с подробностями.
- Раздела «Не закончено» нет: задача со сроком — в портянку, архитектурный хвост — в очередь `iwe-development/log.md`; в записи — только ссылка на них.
- Что считается структурным изменением — `automation/session-close-routing.md`, Блок 7.

## Как прочитать

- Последние записи — `personal_list_path` по `docs/zhurnal/`: дата в начале имени, ветка — следом, заголовок — в списке.
- Картина за период (аудит, перетряска системы) — тот же список как оглавление; открывать только нужные записи.
