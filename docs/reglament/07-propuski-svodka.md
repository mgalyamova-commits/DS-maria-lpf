## 11. ПРОПУСКИ И ДЫРЫ (онтология Missing vs Unknown)

| Тип | Определение | Паттерн |
|---|---|---|
| **Missing** | Данные существуют, но не попали (сбой Samsung Health, агент не прочитал) | **Восстановление данных** |
| **Unknown** | Данных объективно нет (не смогла оценить триггер) | **Рефлексия** |

**Missing → Восстановление данных:**
Агент предлагает гипотезу на основе прошлых дней, но она НЕ становится фактом без Gate.
Формат: «По прошлым вторникам твой сон ≈ Xч. Вероятно, так и в этот раз. Подтверди?»

**Unknown → Рефлексия:**
Агент НЕ строит гипотезы. Задаёт уточняющий вопрос в вечернем чекине.
Формат: «Триггер вчерашнего спада не зафиксирован. Можешь сейчас сказать, что это было?»

**Шаблон дыры:**

[Дата] ПРОПУЩЕНО
Тип: Missing / Unknown
Сон: Xч (Samsung) — если есть
Энергия: X (Samsung) — если есть
Восстановлено: [гипотеза + подтверждено Марией] / [нет]
Остальное: не зафиксировано

**Правило:** не догонять. Начинать с текущего момента.

## 12. НЕДЕЛЬНАЯ СВОДКА

**Назначение:** визуализация ритма, состояния и продвижения. Основа для привычек и глубокого анализа. С 27.09.2026 — также регулярная точка входа в режим «Стратег» (см. алгоритм, шаг 8): недельная сводка даёт факты прошедшей недели, Стратег — интерпретацию и направление вперёд.

**Когда:** воскресенье вечером (после чекина) или понедельник утром.

**Хранение:** `docs/nedelnye-svodki.md` — текущие сводки; прошлые периоды — в `docs/nedelnye-svodki-arhiv-*.md`.

**Трекеры недели:**

| Трекер | План |
|---|---|
| Слот (обучение или финансы) | 7/нед |
| Тренировки | 4/нед |
| DRR | по необходимости, не реже раза в месяц |

**Ежедневная подпитка** — вечерний чекин ([часть 1](01-arhitektura-cikl.md)).

**Алгоритм:**
1. Агент выдаёт Candidate-сводку (только из зафиксированных данных). Для блока «📋 Продвижение по проектам» закрытые задачи берутся из «Выполнено» портянки (`docs/portyanka-obshiy-stek.md`) и, если неделя захватывает прошлый перенос, из архива (`docs/portyanka-arhiv-ГГГГ-ММ.md`) — добавлено 24.09.2026, GATE. Блок «💰 Финансы» (с 03.10.2026, Testing — «посмотрим, как работать будет») Хаб сам не считает: ветка «Финансы» заканчивает еженедельную сверку блоком «Для сводки» из этих строк, Мария переносит его в Хаб. Сверки на неделе не было — ❌, остальные строки пустые.
2. Мария проходит Gate: подтверждает / правит.
3. Утверждённая сводка → одна вставка в `docs/nedelnye-svodki.md`.
4. **Чистка портянки (с 03.10.2026, решение Марии).** Хаб выносит два списка: задачи с `⚠️` (дедлайн прошёл) и задачи без дедлайна старше двух недель. По каждой Мария решает: делаем (ставится дедлайн), снимаем или переносим. Сделанное, но не закрытое — закрывается. Сводка не считается законченной, пока оба списка не пройдены. Правило маркера — [часть 3, раздел 5](03-portyanka-grafik.md), п. 5.
5. **Перенос выполненного в архив (с 24.09.2026, GATE):** после утверждения сводки — все блоки «Выполнено» портянки дословно переносятся в архив текущего месяца, в портянке на их месте остаётся пометка «закрытое до ДД.ММ — в архиве». Механика и правило «только последний статус» — [часть 3, раздел 5](03-portyanka-grafik.md), п. 7–8.
6. **Недельная сверка репозитория** — `automation/repo-map.md` → «Недельная сверка»: новые папки верхнего уровня и сигнал «пора худеть».
7. **Вопрос «Нужен ли DRR?»** Да — проход по [части 9, раздел 16](09-pravila-drr.md). С последнего DRR прошло больше месяца — проход обязателен.
8. **Переход в Стратега (добавлено 27.09.2026, по запросу Марии):** сразу после утверждения сводки (шаг 2) — по умолчанию предложить переход в режим «Стратег» (промпт Дневника, [prompts/dnevnik-prompt.md](../../prompts/dnevnik-prompt.md), раздел STRATEGIZING): «Сводка зафиксирована. Переходим в Стратега?» Не автозапуск — Мария подтверждает или откладывает на другой раз, режим не начинается без ответа. Смысл добавления: раньше Стратег включался только по разовой инициативе Марии и легко забывался/откладывался бесконечно; теперь у него есть регулярная точка входа, привязанная к уже существующему недельному ритуалу, а не отдельное напоминание или расписание.
