## 11. ПРОПУСКИ И ДЫРЫ (онтология Missing vs Unknown)

| Тип | Определение | Паттерн |
|---|---|---|
| **Missing** | Данные существуют, но не попали (сбой Samsung Health, агент не прочитал) | **Восстановление данных** |
| **Unknown** | Данных объективно нет (не смогла оценить триггер) | **Рефлексия** |

**Missing → Восстановление данных:**
Агент предлагает гипотезу на основе прошлых дней, но она НЕ становится фактом без Gate.
Формат: «По прошлым вторникам твой сон ≈ Xч. Вероятно, так и в этот раз. Подтверди?»

**Unknown → Рефлексия:**
Агент НЕ строит гипотезы. Задаёт уточняющий вопрос в вечернем чекине.
Формат: «Триггер вчерашнего спада не зафиксирован. Можешь сейчас сказать, что это было?»

**Шаблон дыры:**

[Дата] ПРОПУЩЕНО
Тип: Missing / Unknown
Сон: Xч (Samsung) — если есть
Энергия: X (Samsung) — если есть
Восстановлено: [гипотеза + подтверждено Марией] / [нет]
Остальное: не зафиксировано

**Правило:** не догонять. Начинать с текущего момента.

## 12. НЕДЕЛЬНАЯ СВОДКА

**Назначение:** визуализация ритма, состояния и продвижения. Основа для привычек и глубокого анализа.

**Когда:** воскресенье вечером (после чекина) или понедельник утром.

**Хранение:** `docs/nedelnye-svodki.md` в репозитории (перенесено из Google Docs 29.08.2026). Append-only (только добавляется). Архив недель до 28.08.2026 — Google Диск → «Недельные сводки.md».

**Трекеры недели:**

| Трекер | План |
|---|---|
| Ритм обучения | 7/нед |
| Тренировки | 4/нед |
| Анализ дневника | 1/нед |
| Цикл улучшений (E.9 DRR) | по необходимости |

**Ежедневная подпитка:** в каждом вечернем чекине:
— Слот: ✅/❌
— Тренировка: ✅/❌
