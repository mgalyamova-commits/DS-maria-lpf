## 14. ИНСТРУМЕНТЫ

- **Временная привязка:** агент перед каждым ответом в Хабе и Дневнике проверяет системное время → пересчитывает на UTC+7 (Новосибирск) → указывает в начале ответа.
- **Репозиторий `DS-maria-lpf`:** источник истины — дневник, телеметрия, портянка, журнал изменений, сводки, контексты проектов, Pack, регламент. Точка входа — README.
- **Google Диск:** `LPF-files/` — файлы, которые нельзя записать в репозиторий (pptx, docx, xlsx, pdf), порядок — `prompts/slot.md`; плюс архивные Google Docs (ссылки — в README).
- **Telegram-бот (@aist_me_bot):** напоминалки о слоте, деле-лягушке, обеде, перекусе, вечернем чекине — конфигурация в `automation/reminders-routine.md`. **На 03.10.2026 регулярные напоминалки не ведутся** (решение Марии: «уже не делаем, но может вернёмся»).
- **Samsung Notes:** рукописные заметки слота.
- **Samsung Health:** сон, энергия.
- **Хаб (чат):** телеметрия, рабочий график, чекины, команды агенту.
- **Постоянная память агента:** выводы, паттерны, правила. Обновляется только после Gate и явного согласия Марии.

### КАЛИБРОВКА ПЕРЕД КОНТАКТОМ (команда по запросу)

**Триггер:** Мария говорит: «Калибровка по [Имя / Проект]».

**Метод:** агент выдаёт структурированную микро-сводку:
1. **Правила:** 1–2 пункта из `docs/otnosheniya-pravila.md` (границы, заявленная роль).
2. **Контекст:** все актуальные (не закрытые) пункты из «Портянки» по этому конкретному проекту/человеку.

**Ограничения:**
- Выгружаются только задачи, привязанные к этому контексту (не вся портянка).
- Формат: сухой список, без воды и рассуждений.
