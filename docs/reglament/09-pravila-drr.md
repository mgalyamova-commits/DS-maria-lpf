## 16. ЦИКЛ УЛУЧШЕНИЙ (E.9 DRR)

**Частота:** по необходимости (не еженедельно).

**Процедура:**
1. Что сработало?
2. В какой ситуации метод не помог? (в т.ч. Reopen Conditions из [части «Ситуации»](05-situacii.md))
3. Что поправить в этом регламенте?

**Результат:** внести правку → обновление версии регламента. Факт DRR фиксируется в недельной сводке.

**Первый DRR:** 22.08.2026 (v2.3 → v2.4).
**Второй DRR:** 24.08.2026 (v2.4 → v2.5).
**Третий DRR:** 28.08.2026 (v2.5 → v2.6) — разбор `docs/drr-candidates.md`, 15 пунктов (12 дневниковых + 3 наблюдения агента), пройдено пункт за пунктом:
  - Gate: «Увольнение = процедура» → `docs/otnosheniya-pravila.md`
  - Gate: «Итог мой — шаг его» + Evidence 27.08 + Reopen Condition → Ситуация 0
  - Gate: «Эмоция — физиология» + фильтр «не коллектор» → Ситуация 6
  - Gate: «Право выйти из чужого процесса» (объединены 2 пункта) → `docs/otnosheniya-pravila.md`
  - Gate: новая Ситуация 11 «Наблюдатель»
