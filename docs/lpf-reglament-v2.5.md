## Почему разбито

`personal_get_document` на этом файле (700+ строк) неоднократно возвращал только часть содержимого (то первый раздел, то последний), даже после форс-реиндекса. Гипотеза: инструмент отдаёт один чанк поискового индекса, а не файл целиком — большие файлы не помещаются в один чанк. См. `automation/agent-workflow-rules.md`, правило 4, уточнение 2.
