# Кандидаты для DRR

*Формат: Ситуация → что зафиксировано → почему кандидат. Gate проходит на самом DRR-цикле (раздел 16 регламента), не здесь — это только список на рассмотрение.*

---

## 1. Ситуация 9 («Жёсткий Gate на ложный сброс», алкоголь)

**Что зафиксировано:** метод (стакан воды + 10 приседаний/2 мин на полу + вслух «это дерьмовый инструмент») действует с 22.08.2026. Несмотря на это, алкоголь по телеметрии повторяется:
- 22.08 — 3 рюмки коньяка (исходный Evidence-кейс)
- 26.08 — 2 рюмки коньяка
- 27.08 — 2 рюмки коньяка, с постфактум-сожалением («не надо было»)

**Почему кандидат:** метод не перехватывает момент тяги — либо гейт не запускается вовремя (осознание приходит постфактум, не в моменте выбора), либо триггер описан слишком широко («вечерняя усталость»), а по факту это что-то конкретнее (марафонский день, накопленное давление). Reopen Condition раздела 8 формально не прописан как числовой порог для этой ситуации, но повторяемость 3 раза за неделю — сигнал пересмотреть либо формулировку триггера, либо сам момент вмешательства (раньше, до вечера).

---

## 2. Ситуация 0 («Порог: мой шаг / чужой шаг»)

**Что зафиксировано:** 27.08.2026 — «день-экзамен»: 5 отдельных триггеров за один день (форум/модерация, подрядчик-друг, вечерний запрос по справке, срыв на ребёнка, звонок из Москвы), паттерн «виновата за всех» пойман и обезврежен в реальном времени по каждому из пяти, а не постфактум.

**Почему кандидат:** это не сбой, а сильное валидационное подтверждение метода под давлением — стоит рассмотреть добавление этого дня в раздел Evidence карточки Ситуации 0 как эталонный кейс (метод работает не только в спокойном единичном случае, но и при множественных триггерах подряд в течение одного дня).
