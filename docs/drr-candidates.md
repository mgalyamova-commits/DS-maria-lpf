# DRR — кандидаты (сквозной список)

Место сбора кандидатов в правки регламента между циклами DRR (раздел 16 `lpf-reglament-v2.5.md`). Пункт попадает сюда сразу при появлении — не только в дневник дня, где родился, чтобы не потерялся к моменту следующего DRR.

**Формат добавления:** дата | что | источник (какой день/ситуация породила) | статус.

**Статусы:** Candidate (предложено, не проверено) → Testing (проверяется на практике) → Gate: принято (ушло в регламент, указать версию) / Gate: отклонено (указать почему).

При проведении DRR: пройтись по всем строкам со статусом Candidate/Testing, для каждой — решить Gate, обновить статус, если принято — внести правку в `lpf-reglament-v2.5.md` и указать новую версию.
