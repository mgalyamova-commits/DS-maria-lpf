## Название проекта

**«Проект создания личного финансового агента»** (по шаблону наставника: Проект <метод> <результат-система/документ>, согласовано 16.09.2026).

## Проект (согласован с наставником 16.09.2026)

- **Что не устраивает:** нет дисциплины и инструментов для работы с семейными финансами. Сколько получаем, столько тратим, периодически кассовые разрывы.
- **Зачем менять:** в следующем году доход просядет минимум на полгода (заканчивается проект, вносивший существенный вклад в доход), а траты остаются — дача, машина, накопления детям на квартиры.
- **Целевой результат (горизонт резидентуры, не недели 1):** управляемый «план=факт» доходов и расходов с минимальным ручным участием, встроенный в личную рабочую среду (IWE).
- **Ритм (уточнено наставником 16.09.2026):** 2 помидорки в день, стандарт 25+25 минут (можно меньше 15+15 или больше). Первая помидорка — самостоятельное описание, вторая — вместе с ИИ, включая просьбу прокритиковать через FPF.
- **Где нужна помощь:** пока не ясно — вероятно техническая часть (интеграции с банком), если возникнет по ходу.

Три разных типа работы разведены по разным веткам, чтобы не путать сбор/анализ/трекинг практикума в одном чате (по аналогии с разделением «Хаб+Дневник» / «Рабочие проекты» в общей архитектуре, см. [[lpf2-5]]):

## Архитектура семейных доходов/расходов (уточнено 19.09.2026)

- У мужа отдельный счёт, зарплату тратит сам — не единый семейный котёл по умолчанию.
- При этом часть общих статей идёт через его счёт: сейчас в основном его зарплата во многом закрывает стройку дачи.
- Практическое следствие: выписки нужны с обоих счетов (её и мужа) периодически, иначе часть семейных расходов (в первую очередь «Дача — Стройка») выпадет из картины.

## Описание агента как результата проекта

Личный финансовый агент — автоматизированная система, которая собирает данные о доходах и расходах по банковским счетам, сверяет их с планом, прогнозирует кассовые разрывы и даёт понимание, хватит ли средств на запланированные крупные траты при снижении дохода. Работает с минимальным ручным вводом со стороны пользователя.

## Рабочие продукты, которые создаёт агент (согласовано с наставником 16.09.2026)

1. Ежемесячный отчёт план=факт (доходы/расходы по категориям)
2. Прогноз кассового разрыва / остатка на горизонт 3-6 месяцев
3. Сигнал о превышении лимита по категории (при внедрении бюджетирования по категориям)
4. Годовой прогноз с учётом просадки дохода — хватит ли на дачу/машину/квартиры

### РП2 «Обещание» — финал (24.09.2026)

> Система показывает мне, как каждая моя трата двигает шансы дойти до цели, которую я сама задаю и могу поменять в инструменте (закрыть кредитку, накопить на машину, на отпуск и т.д.) — так, чтобы я видела не «сколько потратила», а «сколько это стоило мне до цели», и могла на этом основании решать, тратить или нет.

- Обещание личное (Марии себе), не семейное — решения по финансам принимает она.
- Архитектурное следствие: цель — не константа, а редактируемая сущность (завести / сменить / закрыть цель), прогноз всегда считается от текущей активной цели.
- Проверка на предъявляемость: артефакт — экран/отчёт, где рядом с суммой траты стоит изменение прогноза по текущей цели.

### РП3 «Сценарий использования системы» — финал (24.09.2026)

1. **Еженедельная сверка.** Выгружает выписки всех банков (свой счёт + счёт мужа) → видит траты по категориям (неделя/месяц) → проверяет и довосстанавливает автораспределение → ОК/поправить. В её же составе — видит итог по **текущей** цели (без права её менять здесь).
2. **Прогноз кассового разрыва.** Обязательные платежи + прогноз трат + плановые поступления → «плюс-минус» на 1–4 недели → рекомендации по оптимизации при минусе (перенести платёж, подрезать расход).
3. **Долгосрочное планирование.** Строит прогноз на длинный период → видит, какие цели может себе позволить → здесь же заводит/меняет/закрывает цель.
4. **Проверка перед крупной тратой.** До траты спрашивает систему, как это скажется на цели/риске минуса.

Сценарий подбора более выгодных финансовых инструментов рынком (изначально предложен как отдельный сценарий) — вынесен за пределы недели 2, соотнесён с сессией 4 «анализ мирового опыта», но остаётся отдельной сессией, не смешивается (уточнено Марией 24.09.2026).
