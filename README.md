# README — Мария (точка входа)

## Для нового агента (прочитай первым)

Ты — одна из веток системы Марии. При первом запуске:

1. Прочитай этот README полностью — здесь архитектура всех файлов.
2. Найди свою ветку в разделе «Инструкции для веток» ниже.
3. Прочитай промпт/регламент своей ветки — это твой формат, тон и алгоритм общения.
4. Часовой пояс: Новосибирск (UTC+7). **Обязательная процедура для Хаба и Дневника — см. регламент, [часть 1](docs/reglament/01-arhitektura-cikl.md), раздел «Временная привязка»: перед каждым ответом определить системное время → пересчитать на НСК → указать в начале ответа. Не разово при старте сессии, а на каждое сообщение.**
5. **Если твоя работа предполагает создание, изменение или удаление файлов репозитория** (не только чтение памяти) — обязательно прочитай [automation/agent-workflow-rules.md](automation/agent-workflow-rules.md) перед первой такой операцией в сессии. Это отдельный от LPF-регламента слой: технические правила работы с инструментами и файлами репо, не про психологию пользователя.
6. **При создании нового файла в этом репозитории** — в той же сессии добавь на него ссылку в этот README (кандидат в обязательное правило с 28.08.2026, см. `automation/agent-workflow-rules.md` → «Кандидаты»).
7. **Если начинаешь сессию не с чистого листа** — загляни в [docs/zhurnal-izmeneniy.md](docs/zhurnal-izmeneniy.md) (последняя запись) **и в [docs/portyanka-obshiy-stek.md](docs/portyanka-obshiy-stek.md)** (полный стек задач): вместе они показывают, что не закрыто с прошлой сессии — журнал про структурные изменения и отчёты, портянка про конкретные незавершённые задачи по проектам. Один без другого даёт неполную картину (обновлено 31.08.2026).
8. **Gate: аналитика/выводы/резюме агента — только после явного «да»/«принято» Марии** (сначала черновик в чат, запись — после подтверждения). Это касается любого вывода, интерпретации или обобщения агента — не фактов и не текста, продиктованного Марией дословно. Правило распространяется на все ветки независимо от того, читают ли они LPF-регламент целиком (там оно тоже есть, в части 2) — см. `automation/agent-workflow-rules.md`, правило 9, где зафиксировано нарушение 31.08.2026 и его причина.
9. **Верификатор — независимая проверка для значимых решений (пилот с 05.09.2026, см. `automation/role-trials.md`).** Если вывод/решение подпадает под критерий высокой цены ошибки (архитектурные решения по IWE, тексты для внешней аудитории, серьёзные развилки) — не полагаться только на проверку тем же контекстом, который его сделал. Практический протокол (Мария работает в чат-режиме, без инструмента запуска суб-агентов): предложить готовый пакет — короткий текст с артефактом и критериями проверки — и попросить Марию вставить его в новый чат без истории; вердикт из того чата приносится обратно и учитывается здесь. Применимо к любой ветке, не только проектной.

Для проектов научного происхождения (вуз/институт, ранняя стадия) дополнительно доступен специализированный метод — [prompts/fpf-nauchny-proekt-metod.md](prompts/fpf-nauchny-proekt-metod.md) (и человеческая версия [prompts/fpf-nauchny-proekt-gaidlayn.md](prompts/fpf-nauchny-proekt-gaidlayn.md)), вызывается фразой «ФПФ для научного проекта» — см. раздел «Промпты веток» выше.

Работает по умолчанию в любом проектном чате, не только при активации Аналитика (см. `automation/role-trials.md`).
- **При закрытии сессии** — пройти [automation/session-close-routing.md](automation/session-close-routing.md) (добавлено 05.09.2026).

### Треки обучения (FPF, Управление наукой, Распожаризация, IWE/Экзокортекс)
- При запуске: прочитай README, затем сводную заметку своего трека (см. раздел «Обучение (сводные)» выше).
- **Gate (см. пункт 8 выше):** треки обучения не читают LPF-регламент целиком, но Gate на них распространяется — черновик аналитики/выводов в чат, запись только после «да»/«принято».
- **Ограничение опоры на материал (добавлено 02.09.2026, введено Марией явно для трека «Распожаризация»):** при выполнении заданий опираться только на текущий и уже пройденные разделы курса, не на весь корпус руководств. Если material текущего/пройденных разделов недостаточно для задания — явно сообщить об этом Марии, а не молча привлекать материал из непройденных разделов.
- **Распожаризация (с 30.08.2026):** локальные рабочие файлы по заданиям курса — в [raspozharizaciya/](raspozharizaciya/), по одному файлу на задание (`r1-1-tasks1-opisanie-sistemy.md`, `r1-1-tasks3-utochnenie-ekspluatatsii.md`, `r1-1-tasks5-ocenka-epistemy.md`, `r1-1-tasks6-hronometrazh-metodika.md`, `r1-2-tasks1-zazemlennost-zadachi.md`), плюс разбор ошибок к заданию (`r1-1-tasks3-razbor-oshibok.md`, создан 01.09.2026) и журнал хода рассуждений [raspozharizaciya/log.md](raspozharizaciya/log.md) (одна запись на сессию, отдельно от чистовых ответов). Свободные рабочие заметки Марии, не привязанные к конкретному заданию — [raspozharizaciya/zametki.md](raspozharizaciya/zametki.md), создан 06.09.2026: Мария пишет черновик, агент причёсывает и складывает сюда. Сквозной пример курса — венчурный фонд deeptech-инвестиций (реальный проект Марии, он же ЦПИ/стартап-студия), поэтому релевантные разборы также дублируются проектной выжимкой в `startup-studio/` — см. раздел «Проекты — рабочий контекст». Задание R1.1:Tasks6 (хронометраж) — особый случай: его методика реализована прямо в механике Хаба и Дневника (см. регламент часть 3 раздел 7 и промпт Дневника раздел EVENING), а не только описана в файле задания.
- **Обучающие мероприятия вне трека (с 05.09.2026):** конспекты отдельных семинаров/вебинаров — в [obuchenie/](obuchenie/), один файл на мероприятие (см. раздел «Обучение (сводные)» выше). Не привязаны к конкретному курсу с заданиями.
- **Роль «Навигатор» для трека «Распожаризация» (добавлено 03.09.2026):** курс идёт на платформе IWE (МИМ), поэтому роль «Навигатор» (сопровождение в развитии — траектория, ритм, мотивация, из инструкций IWE) может подключаться поверх обычной работы трека. Включается префиксом «Навигатор, ...» в начале сообщения. Не заменяет разбор конкретных заданий (`raspozharizaciya/`, лог рассуждений) и не отменяет Gate — только добавляет взгляд на прогресс/ритм прохождения курса, когда Мария явно просит. Для остальных треков (FPF, Управление наукой, IWE/Экзокортекс) роль пока не подключена — не выяснено, идут ли они через IWE-платформу.
- **При закрытии сессии** — пройти [automation/session-close-routing.md](automation/session-close-routing.md) (добавлено 05.09.2026) — закрывает проблему, что рабочие задачи и инсайты из трека раньше зависали здесь без переноса в проектные чаты/портянку. Дополнено вечером того же дня разделом «активный перенос в практику»: не дожидаться, пока инсайт «всплывёт» сам — специально пересмотреть материал сессии целиком и спросить, что применимо к работе/жизни (обычные назначения — `context.md`/портянка, плюс Pack и [docs/videnie.md](docs/videnie.md) для устойчивого знания и смены направления).
- Сюда идут: учебный материал, конспекты, вопросы по теме.
- Сюда НЕ идут: рабочие задачи → в проектные чаты.
