# README — Мария (точка входа)

## Для нового агента (прочитай первым)

Ты — одна из веток системы Марии. При первом запуске:

1. Прочитай этот README полностью — здесь архитектура всех файлов.
2. Найди свою ветку в разделе «Инструкции для веток» ниже.
3. Прочитай промпт/регламент своей ветки — это твой формат, тон и алгоритм общения.
4. Часовой пояс: Новосибирск (UTC+7). **Обязательная процедура для Хаба и Дневника — см. `docs/lpf-reglament-v2.5.md`, раздел 1 («Временная привязка»): перед каждым ответом определить системное время → пересчитать на НСК → указать в начале ответа. Не разово при старте сессии, а на каждое сообщение.**
5. **Если твоя работа предполагает создание, изменение или удаление файлов репозитория** (не только чтение памяти) — обязательно прочитай [automation/agent-workflow-rules.md](automation/agent-workflow-rules.md) перед первой такой операцией в сессии. Это отдельный от LPF-регламента слой: технические правила работы с инструментами и файлами репо, не про психологию пользователя.
6. **При создании нового файла в этом репозитории** — в той же сессии добавь на него ссылку в этот README (кандидат в обязательное правило с 28.08.2026, см. `automation/agent-workflow-rules.md` → «Кандидаты»).

## Инструкции для веток

- LPF-регламент v2.6: [docs/lpf-reglament-v2.5.md](docs/lpf-reglament-v2.5.md)
- При запуске: прочитай README, затем LPF-регламент целиком (включая раздел 1 — «Временная привязка», обязательная процедура на каждый ответ, не только при старте сессии).
- Твои задачи: телеметрия, рабочий график, портянка, чекины, команды агенту, недельная сводка ([docs/nedelnye-svodki.md](docs/nedelnye-svodki.md), формат — раздел 12 регламента).

### Дневник (Жилетка / Друг с битой / Пледик / Подружка / Стратег)
- Промпт: [prompts/dnevnik-prompt.md](prompts/dnevnik-prompt.md)
- Живой лексикон: [prompts/dnevnik-lexicon-live.md](prompts/dnevnik-lexicon-live.md)
- НЭП (неудовлетворённости): [docs/neudovletvorennosti.md](docs/neudovletvorennosti.md)
- При запуске читать, в этом порядке (обновлено 29.08.2026):
  1. README
  2. LPF-регламент, раздел 1 («Временная привязка») — обязательная процедура на каждый ответ: определить системное время → пересчитать на UTC+7 (Новосибирск) → указать в начале ответа «[день недели, дата, время НСК]»
  3. LPF-регламент, разделы «Правила несмешивания» и «Episteme-карточки»
  4. [docs/otnosheniya-pravila.md](docs/otnosheniya-pravila.md) — правила коммуникации с конкретными людьми нужны сразу, не только когда всплывёт имя
  5. [docs/o-marii-fakty-lyudi.md](docs/o-marii-fakty-lyudi.md) — факты о людях в жизни Марии, чтобы не переспрашивать то, что уже известно
  6. [docs/neudovletvorennosti.md](docs/neudovletvorennosti.md) — список неудовлетворённостей, для контекста режима «Стратег», даже если сессия сегодня не про это
  7. **Вчерашняя запись в [telemetry/diary-2026-08.md](telemetry/diary-2026-08.md)** — эмоциональный фон и триггеры вчерашнего дня, чтобы не начинать разговор с чистого листа
  8. Промпт ветки
  9. Живой лексикон
  Затем запроси у Марии текущую телеметрию (сон, энергия, ёмкость, контекст дня, было ли отключение Дневника из-за технических проблем и когда).
- **PEOPLE INTAKE (добавлено 28.08.2026):** по ходу разговора расспрашивать о людях, которых упоминает Мария, и по итогу раскладывать новое в факты (`docs/o-marii-fakty-lyudi.md`, напрямую) или в кандидаты правил (`docs/otnosheniya-pravila.md`, через DRR). Подробности — в промпте ветки.
- **СТРАТЕГИРОВАНИЕ (добавлено 29.08.2026):** по команде Марии («давай стратегируем») — режим глубокого мышления письмом о направлении на месяц вперёд, отдельно от повседневного протокольного тона. Не по расписанию. Подробности — в промпте ветки, раздел STRATEGIZING.
- Сюда идут: состояние, эмоции, жалобы, отношения, стратегирование по команде, а также просто разговор (режим Подружки). Мототренировки — трек (взятые/не взятые препятствия, падения) идёт в [docs/moto-dnevnik.md](docs/moto-dnevnik.md), а эмоциональный фон вокруг тренировки — сюда, в общий дневник.
- Сюда НЕ идут: статусы задач, детали проектов, рабочий график.
