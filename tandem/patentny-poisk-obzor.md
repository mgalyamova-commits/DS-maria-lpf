# TANDEM AMR — Предварительный патентный поиск

## 1. Описание системы TANDEM AMR

### 1.1. Общее описание

Система TANDEM AMR — автономная система транспортировки паллет стандарта EUR/FIN, состоящая из двух физически независимых роботизированных модулей. Каждый модуль целиком въезжает под паллету с продольной стороны через канал паллеты; затем оба модуля совместно поднимают и транспортируют паллету. Ближайший публичный аналог — система FILICS STREAMLINER производства FILICS GmbH (Германия).

### 1.2. Аппаратура каждого модуля

| Компонент | Характеристика |
|---|---|
| Габариты | до 1400×220×95 мм |
| Вычислитель | Raspberry Pi 5, ROS2 Jazzy Jalisco |
| Привод | 2 мотора: 1 приводное + 1 рулевое колесо (велосипедная/Ackermann кинематика), полиуретан |
| Лидары | 2 шт./модуль (передний+задний), ~180° каждый — суммарное 360° покрытие пары |
| Камеры | 2 шт./модуль (QR-код + опциональный Intel RealSense RGBD) |
| Связь | Wi-Fi DDS ≥20 Гц + резервный радиоканал 900 МГц / 2,4 ГГц FHSS |
| Подъём | Двойной кривошипный механизм с линейным актуатором ШВП (HAKIWO); ход ~70 мм; самоторможение |

### 1.3. Программный стек

SLAM: slam_toolbox (lifelong mapping, 2D лидар, только master-модуль). Глобальный планировщик: Smac Planner (неголономные системы). Локальный планировщик: DWB / TEB (Ackermann). Интерфейс с RMS: Nav2 Action Server (rosbridge_suite / WebSocket, React UI).

### 1.4. Архитектура master-slave

Master: SLAM, глобальное планирование, приём заданий от RMS, отправка команд slave. Slave: исполнение команд master; собственные сенсоры — только для локальной безопасности. Позиция slave вычисляется геометрически из позиции master + фиксированное смещение (расстояние между пазами паллеты); собственного глобального SLAM нет. Watchdog: heartbeat ≥20 Гц; потеря связи >500 мс — аварийная остановка обоих модулей одновременно. Нет смены ролей: slave никогда не становится master. Контроль рассогласования: расхождение позиций >±20 мм — аварийная остановка.

### 1.5. Концепция «виртуальной велосипедной рамы»

При нахождении под паллетой оба Ackermann-модуля управляются как единый виртуальный велосипед большой колёсной базы: вычисляется общий мгновенный центр поворота (ICC), из которого выводятся согласованные радиусы поворота обоих модулей — единая bicycle-модель. Режимы: «сцепленный» (пара под паллетой) и «разделённый» (каждый модуль автономен).

### 1.6. Подъёмный механизм (двойной кривошипный привод)

Два треугольных кривошипа на ~25% и ~75% продольной длины модуля, кинематически связаны одним линейным актуатором ШВП. Расталкивание кривошипов актуатором → синхронное вращение вокруг фиксированных осей → подъём крышки. Ход подъёма ~70 мм. Самоторможение ШВП удерживает поднятое положение при обесточивании (критично при аварийном стопе). Один актуатор управляет двумя точками подъёма через жёсткую кинематическую связь — электронная синхронизация точек не требуется.

### 1.7. Процедура выравнивания и заезда (конечный автомат)

APPROACH → ALIGN_COARSE → ALIGN_FINE → ENTER → LIFT → DONE/ERROR. Грубое выравнивание — по QR-коду камерой; точное (Y<5 мм, θ<1°) — лидарная кластеризация облака точек.

## 2. Рекомендуемые патентные заявки

### 2.1. Заявка A1 — Двухмодульная система подпаллетного транспортирования с велосипедной кинематикой

Суть: два физически независимых автономных модуля с велосипедной (Ackermann) кинематикой (1 приводное + 1 рулевое колесо), въезжающих в продольные каналы EUR-паллеты и совместно её поднимающих.

Охраняемые признаки: (1) два физически независимых модуля с велосипедной кинематикой; (2) полный заезд каждого модуля в продольный канал паллеты (EUR/FIN); (3) совместный подъём паллеты обоими модулями; (4) беспроводная синхронизация ≥20 Гц; (5) управление системой как единым виртуальным велосипедом с общим ICC; (6) переключение режимов «сцепленный»/«разделённый».

Вид охраны: Изобретение (система+устройство) + Полезная модель на конструкцию модуля (ускоренная защита, ~6–12 мес.). Патентоспособность: **очень высокая** — по результатам глобального поиска (Google Patents, WIPO PATENTSCOPE, ФИПС, Perplexity) прямых аналогов не найдено ни в одной базе мира. Ближайший конкурент FILICS GmbH использует омни-роликовый привод (иная кинематика) и не имеет охраны в России.

### 2.2. Заявка A2 — Способ и система синхронизации двух автономных модулей без смены ролей

Суть: SLAM-локализация и глобальное планирование — только на ведущем модуле; ведомый вычисляет глобальную позицию геометрически (смещение от позы ведущего на фиксированный вектор, соответствующий расстоянию между пазами паллеты). Сторожевой таймер — одновременная остановка обоих при потере связи.

Охраняемые признаки: (1) SLAM/планирование только на ведущем; (2) поза ведомого = T(поза ведущего, вектор смещения, ориентация ведущего) без собственного SLAM; (3) сторожевой таймер — одновременная авария при потере heartbeat >T мс; (4) контроль рассогласования с порогом остановки (±X мм); (5) ведомый использует сенсоры только для локального избегания препятствий; (6) отсутствие смены ролей при любых условиях, включая потерю связи.

Ключевые отличия от аналогов: DE102024127549A1 (FILICS) — ведомый может перехватить управление при критических данных сенсоров, в TANDEM смена ролей конструктивно исключена; EP4269321A2 (FILICS) — идентичное ПО на обоих блоках с метрикой качества данных, в TANDEM роли и ПО принципиально различаются.

Вид охраны: Изобретение (способ+система). Патентоспособность: высокая.

### 2.3. Заявка A3 — Способ многоэтапного выравнивания и синхронного заезда двух модулей под паллету

Суть: конечный автомат из 5 этапов; грубое выравнивание — QR-код; точное — лидарная кластеризация облака точек. Синхронный въезд с непрерывным контролем отклонения.

Охраняемые признаки: (1) КА APPROACH–ALIGN_COARSE–ALIGN_FINE–ENTER–LIFT для двух модулей; (2) QR-код как маркер грубой ориентации; (3) лидарная кластеризация для точной позы паллеты (Y<5 мм, θ<1°); (4) синхронный одновременный въезд с подтверждением каждого шага; (5) количественные пороговые критерии перехода между этапами; (6) непрерывный контроль бокового отклонения при въезде.

Ключевое отличие от FILICS WO2026068509A1 (PCT 2026): FILICS использует горизонтальный массив дальномеров («подсчёт блоков» паллеты по поперечному сечению) — TANDEM использует кластеризацию облака точек 2D лидара + QR-код, принципиально иной метод.

Вид охраны: Изобретение (способ). Патентоспособность: высокая.

### 2.4. Заявка A4/ПМ — Подъёмный механизм на основе двойного кривошипного привода с линейным актуатором

Суть: механизм для сверхнизкопрофильного модуля (высота ≤95 мм). Два треугольных кривошипа на 25%/75% длины, связаны одним линейным актуатором ШВП. Расталкивание актуатором → синхронное вращение вокруг фиксированных осей → подъём крышки, контактирующей с нижней поверхностью паллеты.

Охраняемые признаки: (1) два треугольных кривошипа с фиксированными осями на ~25%/75% длины; (2) единый линейный актуатор (ШВП), расталкивающий кривошипы в противоположных направлениях; (3) механическая синхронизация двух точек подъёма через единую кинематическую цепь (без электронной синхронизации); (4) подъёмная крышка, соединённая с обоими кривошипами; (5) самоторможение ШВП без подачи питания; (6) ход подъёма ≥70 мм при высоте модуля ≤95 мм.

Ключевое отличие от FILICS EP4174015B1 (дорожный просвет): FILICS патентует принцип «компоненты поднимаются вместе с несущей рамой через профилированную нижнюю поверхность». В TANDEM подъёмная крышка поднимается независимо от корпуса и всех компонентов — принципиально иное решение, не попадающее в объём охраны EP4174015B1.

Вид охраны: Полезная модель (~6–12 мес., не требует изобретательского уровня) + параллельно Изобретение (устройство). Патентоспособность: высокая — сочетание «сверхнизкий профиль ≤95 мм + двойной треугольный кривошип + один ШВП-актуатор + самоторможение» в контексте подпаллетного AMR аналогов не обнаружено.

## 6. Рекомендации по проектированию (design-around)

**6.1. EP4174015B1 (FILICS) — дорожный просвет.** Не применять принцип «компоненты (сенсоры, АКБ, электроника) поднимаются вместе с несущей рамой через профилированную нижнюю поверхность». Альтернативы: телескопические опоры, разделённая конструкция рамы, независимый механизм дорожного просвета.

**6.2. DE102019001125B4 (FILICS) — расположение сенсоров.** Провести детальный claim chart перед выходом на рынок ЕС. Design-around: 3D лидары вместо 2D плоскостных сканеров меняют объект охраны (патент защищает специфику 2D плоскости сканирования).

**6.3.
