## Метод «Обучить инструменту» (модель, применима к любому обучающему мероприятию Каталиста)

| Поле | Значение |
|---|---|
| Задача | Провести обучающее мероприятие по конкретному инструменту в рамках Каталиста |
| Цель | Обучить студентов инструменту для применения в их проектах |
| Польза | Меньше ошибок в работе над проектом, выше шанс успешной реализации, экономия времени на самостоятельном сборе граблей |
| Результат | Проверенное умение студента применять инструмент (подтверждено принятой домашкой/артефактом) |
| Метод | Обучить инструменту |
| Объект | Студент Каталиста |
| Характеристика | Владение инструментом |
| Состояния | Не владеет → владеет (применяет инструмент в своём проекте) |
| Действия | Рассказать/показать → ответить на вопросы → домашка с применением к проекту → проверка сданного артефакта |

Рецепт один и тот же под разными форматами (лекция, игра, практикум, разбор кейса, встреча с экспертом).

## Работы по методу — практикум CusDev

Экземпляр: практикум по CusDev, **02.10.2026 (пятница)**, спикер — **Никита Николаенко**, ожидается 50–70 студентов. Это описание **планируемой** работы: сроки — план, не факт.

| # | Работа | Результат (рабочий продукт + состояние) | Срок |
|---|---|---|---|
| 1 | Согласовать сценарий со спикером: длительность лекции, активность и что для неё нужно, баллы за активность, проверка артефактов, домашка | Параметры практикума согласованы | вт 29.09, планёрка |
| 2 | Записать в сценарий (паспорт сценария ещё не доработан) | Сценарий практикума | вт 29.09, планёрка |
| 3 | Анонсировать по доступным каналам (с плюшками и бонусами); подготовка анонса — на планёрке | Анонс опубликован | 29–30.09 |
| 4 | Подготовить реквизит, интерактив, инфраструктуру площадки | Всё нужное для активности есть | 30.09–01.10 |
| 5 | Подготовить площадку: презентация, микрофоны, рассадка, реквизит, подключения | Площадка готова | пт 02.10, до начала |
| 6 | Провести по сценарию вместе со спикером: лекция → практическое задание → обратная связь по нему | **Студент: не владеет → владеет CusDev** | пт 02.10 |
| 7 | Начислить баллы и бонусы за активность, сообщить студентам | Баллы начислены, студенты знают | сб 03.10 |
| 8 | Объявить домашку | Домашка выдана | пт 02.10 |
| 9 | Собрать домашку | Домашки сданы | до пт 09.10 |
| 10 | Проверить домашку | Владение подтверждено (или нет) | до пт 09.10 |
| 11 | Начислить бонусы за домашку | Бонусы начислены | до пт 09.10 |
| 12 | Внутренний постмортем: что так, что не так | Разбор зафиксирован | вт 06.10, планёрка (см. «Открыто») |

**Где меняется состояние студента:** только в строке 6 (лекция → практика → обратная связь). Строка 10 его только подтверждает. Остальные строки — работы по другим методам (организация, анонс, бонусы, разбор), которые обслуживают это изменение.
