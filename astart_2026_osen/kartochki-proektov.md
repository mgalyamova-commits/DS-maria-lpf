- **Суть:** отечественные наборы реагентов для контроля качества мРНК-препаратов (двуцепочечная РНК, фрагментированность, технологические примеси).
- **Стадия (заявлено):** ранний НИОКР / концепция; «интерес партнёра» — устный, источник не назван.
- **Что вскрылось на сессии 1:**

  - производителей мРНК в РФ почти нет (единственный реальный контакт — [неразборчиво, похоже, Центр Гамалеи]), рынок сейчас фактически научный; без личного выхода на производителей для инвестора рынка нет;

- **ДЗ:**
  - кастдев вести таблицей (кто, контакт, как задан вопрос); прошлый разговор восстановить по памяти;
  - экономика: материальная себестоимость по каталожным ценам ×5 — пол цены, лучше ×10; цену узнавать у покупателей, свою не называть;
  - вопросы проблемного интервью подготовить и разобрать с трекерами заранее;
  - отдельный разговор без записи — про отношения с Биолабмикс.
- **Открыто:** ветка «разработка» vs «производство»; кто ещё может выпускать мРНК в РФ; форма отношений с Биолабмикс.
- **Статус:** кандидат в воронку СД (решение Марии 27.09.2026) — собираем информацию под справку «6 осей».

## 2. XanOil

- **Команда:** Слажнев Иван (4 курс ФЕН, лаборант, грант УМНИК).
- **Суть:** ксантан для нефтедобычи из дешёвого сырья (меласса, личинки чёрной львинки) с осаждением солями металлов; цель — 300–400 ₽/кг; сейчас ксантан на 100% импортный.
- **Стадия:** штаммы и реагенты заказаны, эксперименты начинаются; в ноябре — депонирование штаммов.
- **Что вскрылось:**
  - прямой конкурент — завод в Тольятти (~40 млрд инвестиций, стройка с 2026, выпуск 2028), стандартная спиртовая технология, дешевизна за счёт масштаба;
  - разрыв бизнес-модели: «грязный» ксантан — только нефтянка; малый объём = высокая себестоимость на единицу, большой = отдельный завод; контрактного производства такого объёма в РФ нет;
  - второй игрок режет рынок пополам; гранты/кредиты вряд ли — Тольятти уже профинансирован;
  - нефтяник не будет тестировать без гарантии промышленного объёма;
  - вердикт трекеров: пока научная работа, не бизнес.
- **ДЗ:** данные по объёму мирового рынка; Excel — гипотетическая себестоимость стандартной технологии vs своей (снижение на 10–20% никому не интересно); проверить другие отрасли применения.
- **Открыто:** под какой существующий завод продавать технологию (лицензия вместо своего производства?); упомянута договорённость с Газпромом [неразборчиво].

## 4. БОС-Н (БиоОргСин-Нуклеозиды)

- **Суть:** первое в РФ производство полного цикла: нуклеозиды → трифосфаты (ПЦР, мРНК) → кэп-аналоги → фосфорамидиты (синтез олигонуклеотидов).
- **Стадия:** идея / разработка; грант «Студенческий стартап» на получение сырья (нуклеозидов).
- **Что вскрылось:**
  - боль по её интервью с производственниками — логистика и воспроизводимое качество;
  - логистика как боль не убеждает: заявлено 150–180 дней, у работающих с постоянными объёмами авиадоставка из Китая ~7 дней;

  - если себестоимость низкая за счёт работы в одиночку без наёмных — модель не масштабируется.
- **ДЗ (срочно, за день):** список покупателей (по оценке — до десятка), разделить на мелких и крупных; обзвонить с конкретным предложением («амидиты по X»), узнать их текущую цену и объём; посчитать себестоимость ×3 × готовый объём; отчитаться в чат, не дожидаясь встречи.
- **Открыто:** качественное преимущество, ради которого будут брать у неё.

## 6. TERRUS BioShield / Биоплатформа регенеративного земледелия (НИИ «Леонардит»)

- **Команда:** Хакимов Руслан (менеджер проекта), Самсонов Сергей (руководитель, автор изобретений); третий не определён; по словам команды — 2 доктора наук.
- **Суть:** безреагентная переработка леонардита, торфа, бурого угля в гуминовые биостимуляторы для АПК; плюс DSS-платформа для агронома, фракции для медицины, в перспективе углеродные/графеновые материалы.
- **Стадия:** идея; 2 патента; ждут решения по гранту 5 млн; в реестре МТК; идут на EasyPitch. Запрос — упаковка для инвестора.
- **Что вскрылось:**
  - суть технологии не объяснена за 4 попытки — чёрный ящик;
  - заявленные цифры без подкрепления: 18 ₽/л против 65 ₽/л у конкурентов; бурый уголь → «леонардитоподобный» продукт с затратами ~1 000 ₽ против 15–18 тыс. ₽ за леонардит;
  - при рознице ~600 ₽ за бутылку экономия ~50 ₽ для покупателя, скорее всего, несущественна;
  - слайд конкурентов сравнивает технологии, а не компании, и смешивает несопоставимое (патент рядом с ценой);
  - «экосистема» — не продукт; графен вынесен за рамки.
- **ДЗ:**
  - две таблицы: (1) структура себестоимости стандартной технологии vs своей на тонну сырья — за счёт какого шага снижение; (2) сравнение с компаниями-конкурентами по потребительским свойствам (без патентов);
  - к следующей субботе рассказать проект простым языком — у инвестора будет 3 минуты и одна попытка; тренироваться на людях, в т.ч. на лекции Дениса.

## 8. Ультимафаг

- **Команда:** Латарцев Константин (руководитель, аспирант ФЕН, лаборатория молекулярной микробиологии ИХБФМ), Федорец Валерия (инженер ИХБФМ, биоинформатика), Пономарев Александр. Пришли с СВЯ.
- **Суть:** препарат на основе бактериофагов против *Acinetobacter baumannii* для стационаров.
- **Стадия:** идея / разработка; коллекции фагов нет, доступа к больничным пробам нет.
- **Что вскрылось:**
  - первое узкое место — пробы из больничной канализации (не водоканал, а стояк/ревизия в подвале стационара);
  - путь к пробам — официальное письмо от директора ИХБФМ (или от НГУ) в 3–5 больниц; через ЦНМТ (ИХБФМ — учредитель) проще;
  - искать партнёра по разработке рано;
  - главный вопрос: зачем больнице отдельный препарат, если колистиметат натрия и другие антибиотики широкого спектра уже закуплены; лечение — по протоколам, нужно найти точку выбора.
- **ДЗ:**
  - проект официального письма — в чат (проверит в т.ч. коллега, «чёрный пояс по бюрократии»);
  - таблица конкурентов по МНН: производители, лекарственные формы, объёмы в рублях (DSM Group и аналоги);
  - изучить открытые материалы НИИ антимикробной химиотерапии (Смоленск, Роман Козлов) по *A. baumannii*; после этого — выход на контакт через Марию.
