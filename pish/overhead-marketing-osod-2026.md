**Флаги шага 1:**

- Видео дублируется: Павлова (ОППИШ) + Зайцева (ОСОД), ~1,1 млн с налогами за 8 мес. вдвоём.

- Конин в загруженном файле ДПО (ред.1) ещё стоит в ДПО — здесь по решению 24.09 в ОСОД.

## Решения Марии 24.09.2026

- Хакатоны («Цифровые недра», СИБУР) — отдельный центр затрат **«событийный маркетинг ВО»**, кладутся только в ВО. В него — все строки ведомости с проектом хакатона: эксперты (392 тыс.), строки сотрудников ОСОД (73 тыс.), компенсации маркетинга (147 тыс.) — итого 612 762 на руки, 917 тыс. с налогами. Правило по тегу проекта; часть компенсаций по содержанию — реклама ДО/ДПО (Бреннер 38,5 тыс., часть Галямовой) — можно перекинуть в файле.
- Overhead = Маркетинг + ОСОД без хакатонов: 6 849 356 на руки, **10 250 414 с налогами за 8 мес.** Разносится **поровну на ВО, ДПО, ДО — по 1/3** (3 416 805 за 8 мес., ~427 тыс./мес на трек). Спецпродукты overhead не несут.
- Второй сценарий — **overhead −50%**: весь пул × 0,5 (1 708 403 на трек за 8 мес.). Прямые затраты треков не режутся.

## Шаг 2. Экономика треков с overhead (8 мес., с налогами)

|---|---|---|---|
| Чистый доход | 2,00 млн (госзадание) | 1,43 млн | 2,15 млн |

| Покрытие (без / 100% / −50%) | 61% / 30% / 40% | 22% / 15% / 18% | 45% / 26% / 33% |
| Результат в год (×12/8), overhead 100% | −7,1 млн | −12,6 млн | −9,1 млн |

**Точка безубыточности (без / overhead 100% / −50%):**
- ВО: платных студентов сверх 50 бюджетных — 8 / 27 / 17 (при цене 300 тыс./год — допущение агента, не цена НГУ).
- ДО: клиенто-месяцев в месяц 154 / 237 / 196 при текущих 32 — ×4,8 / ×7,4 / ×6,1. Упрощённо: средний чек всех форматов на клиенто-месяц (6 178 ₽), вклад за вычетом 10% НГУ и 5% комиссий с взносами. Модель по секциям/тарифу — в ДО v5.
- ДПО: платящих (стартов) в месяц 34 / 58 / 46 при текущих 14 — ×2,4 / ×4,0 / ×3,2. Без overhead сходится с ред.4 (34).

**Методика:** прямые затраты — из финалов без изменений (ДПО — минус Конин); доход ВО — 60 тыс. × 50 студентов / 12 равномерно, без удержаний; ДО и ДПО — выручка по реестрам, минус 10% НГУ. Годовая оценка — линейная ×12/8.
