- Видео дублируется: Павлова (ОППИШ) + Зайцева (ОСОД), ~1,1 млн с налогами за 8 мес. вдвоём.

## Решения Марии 24.09.2026

- Хакатоны («Цифровые недра», СИБУР) — отдельный центр затрат **«событийный маркетинг ВО»**, кладутся только в ВО. В него — все строки ведомости с проектом хакатона: эксперты (392 тыс.), строки сотрудников ОСОД (73 тыс.), компенсации маркетинга (147 тыс.) — итого 612 762 на руки, 917 тыс. с налогами. Правило по тегу проекта; часть компенсаций по содержанию — реклама ДО/ДПО (Бреннер 38,5 тыс., часть Галямовой) — можно перекинуть в файле.
- Overhead = Маркетинг + ОСОД без хакатонов: 6 849 356 на руки, **10 250 414 с налогами за 8 мес.** Разносится **поровну на ВО, ДПО, ДО — по 1/3** (3 416 805 за 8 мес., ~427 тыс./мес на трек, 5,13 млн в год). Спецпродукты overhead не несут.
- Второй сценарий — **overhead −50%**: весь пул × 0,5. Прямые затраты треков не режутся.
- Конин — ОСОД (в ДПО v2 выключен переключателем Вводные B13 = 0).
- Картина **«ФОТ −50%» (Г)** режет пополам и постоянную, и переменную часть (почасовые группы, второй продавец, комиссии). Overhead в Г не режется — для него свой сценарий.
- На слайдах: вместо «дефицит выручки» — **«сколько надо допвыручки»**; отрицательные результаты — красным.

## Шаг 2–3. Экономика треков с overhead — в финалах

Во все три финала добавлены листы «Overhead» (пул по людям помесячно, доля 1/3, переключатели сценария и учёта) и «Overhead — сравнение» (без / 100% / −50% рядом). ДО v6 — через готовый крючок Вводные B39/B40; ДПО v2 — overhead в фикс точки безубыточности; ВО v4 — хакатоны категорией 3 («Разово»), overhead в «Платных студентах».

**Факт 8 мес., с налогами:**

| | ВО | ДО | ДПО |
|---|---|---|---|
| Чистый доход | 2,00 (госзадание) | 1,43 | 2,15 |
| Прямые затраты | 3,30 (вкл. хакатоны 0,92) | 6,45 | 4,78 |
| Результат без / 100% / −50% | −1,30 / −4,72 / −3,01 | −5,01 / −8,43 / −6,72 | −2,63 / −6,05 / −4,34 |
| Покрытие | 61 / 30 / 40% | 22 / 15 / 18% | 45 / 26 / 33% |

**Год (без / 100% / −50%):**
- ВО как есть: −1,76 / −6,88 / −4,32; ФОТ −50%: +0,12 / −5,00 / −2,44. Платных студентов: 7 / 26 / 17; при ФОТ −50% — 0 / 19 / 10 (цена 300 тыс. — допущение).
- ДО при 37 детях × 4 830 ₽: А −6,73 / −11,85 / −9,29; Г −2,31 / −7,44 / −4,88. Детей для нуля при 6 900 ₽: А — не выходит нигде; Г — 93 / не выходит / не выходит.
- ДПО: как есть −3,94 / −9,07 / −6,51; ФОТ −50% −0,36 / −5,48 / −2,92. Платящих в месяц 34 / 58 / 46 (сейчас 14); при ФОТ −50% — 16 / 40 / 28.

**Сколько надо допвыручки в год (А / как есть; без / 100% / −50%):** ВО 1,76 / 6,88 / 4,32 (в платной выручке 1,95 / 7,65 / 4,80); ДО 8,06 / 14,20 / 11,13; ДПО 4,72 / 10,86 / 7,79. Три трека: 14,5 / 31,9 / 23,2 млн; при ФОТ −50% — 3,1 / 19,9 / 11,4. Формула: убыток ÷ доля рубля, остающаяся после 10% НГУ и комиссий (0,835; в Г — 0,867).

**ДО: сейчас и на максимальной загрузке (год; ДО v6, «Overhead — сравнение», стр. 33–50):** сейчас (факт × 12/8) 37 детей по 4 830 ₽, 32 платящих клиента/мес, 199 тыс./мес; максимум — 144 ребёнка × 6 900 ₽ + смены, 738 тыс./мес. Результат сейчас / макс А / макс Г: без overhead −7,52 / −3,55 / +2,21; overhead 100% −12,65 / −8,68 / −2,92 (допвыручки 15,15 / 10,40 / 3,36); −50% −10,08 / −6,12 / −0,36 (12,08 / 7,33 / 0,41). Переменная часть на максимуме в модели есть: 8 почасовых групп, второй продавец после 60 детей, комиссии % от выручки. Не учтены преподаватели смен (в факте почасовые ~0,84 млн/год).
