# ПИШ — управленческий учёт: задача и метод (разбор 28.09.2026)

*Выжимка из трека обучения «Распожаризация» (сессия 11, 28.09.2026), разбор в терминах R1.2 (метод / работа). Касается предложения из письма 27.09.2026 Головину и Мироносицкому — «наладить внутренний управленческий учёт». Подтверждено Марией в ветке обучения.*

## Что было

- Задача (как формулировала Мария): сократить расходы, не порезав деятельность.
- Метод (предложен в письме 27.09): «внутренний управленческий учёт».
- Позиция по работе: метод предложен, но выполнять работу «по умолчанию» Мария не согласилась — «подтверждаем метод, потом решаем про работу».

## Что подтвердилось

- **Разведение метода и работы — верное.** Согласие руководства с методом не назначает исполнителя. Работа — это исполнитель, ресурсы, срок (поля R1.2:Mod4); в письме 27.09 это уже стоит: «нужен ответ, кто её делает» + «обсуждение объёма и условий». Не брать работу по умолчанию — согласуется с правилами `docs/otnosheniya-pravila.md` («Экспертиза как приглашение»; «С Мироносицким — работа сверх участка только по прямому запросу с условиями»).

## Что поправлено

- **Название метода — действием:** «вести управленческий учёт» (не «внутренний управленческий учёт»).
- **Учёт — метод не задачи «сократить расходы, не порезав деятельность».** Учёт делает видимыми реальную себестоимость и доход по отделам; резать будет кто-то другой и другим методом (слайд 21 деки: отдел видит свою себестоимость и сам решает, кого сократить). Риск: если учёт примут как «метод сокращения», с того, кто ведёт учёт, спросят, почему расходы не сократились.

## Задача, разведённая на две

| | Задача А | Задача Б |
|---|---|---|
| Что | Сделать видимыми доход и расходы каждого отдела | Привязать расходы отдела к его доходной базе |
| Метод | Вести управленческий учёт | Ввести правило финансирования от выручки («50% база + доплата из заработанного») |
| Результат | Регулярный отчёт: себестоимость и доход по отделам | Действующее правило: сколько отдел может тратить — считается от того, что он заработал |
| Чья | Метод предложен Марией, исполнитель не назначен | Решение руководства (в письме 27.09 — открытый вопрос про партнёрскую схему для всех отделов) |

Б без А не работает (не к чему привязывать); А без Б — отчёт, который никого не ограничивает. Сокращение расходов без порезки деятельности — задача руководства поверх обеих.

## Рекомендации

1. **Заземлить «привязаны».** Слово двоякое: «видно, сколько отдел зарабатывает» (А) или «отдел тратит не больше, чем заработал» (Б). Проверка: что физически изменится у руководителя отдела через три месяца — например, получил лимит на квартал, посчитанный от его выручки прошлого квартала.
2. **Overhead — отдельной строкой.** Условие Марии: маркетинг и ОСОД — обязательная инфраструктура, своей доходной базы у маркетинга нет. Формулировка «расходы каждого подразделения — к его доходу» бьёт по этому условию. Правильно: «расходы отделов — к их доходу, overhead — к общей выручке по правилу разнесения».
3. **Развилка до старта А:** «по кассе» или «по договору» (открытый вопрос по экономике в `pish/context.md`). Пока не закрыта — учёт вести нельзя. Это первое решение внутри А, и оно тоже не Марии по умолчанию.
4. **Работу по А не брать по умолчанию.** При разговоре об условиях — поля Mod4 как предмет договора: исполнитель, ресурсы, срок.
