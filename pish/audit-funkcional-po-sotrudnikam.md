## Как этим пользоваться

1. Каждый руководитель направления (ВО / ДПО / ДО) отмечает по списку выше: какие пункты он **регулярно использует**, какие **использовал разово**, какие **не использует вообще**.
2. Пункты без единого «да» ни от одного направления — кандидаты на сокращение в первую очередь.
3. Пункты, которые использует только один человек и не могут быть переданы другому (уникальная экспертиза/контакт) — отдельно пометить как риск при сокращении именно этого человека.
4. Три открытых вопроса по идентификации (Alina без фамилии, статус Elena, разделение ролей Кортунова/Колодкина/Alina по ВО) стоит закрыть до финального решения — иначе можно случайно сократить не того человека или продублировать функцию.
