# ПИШ — заявки на курсы ДПО БИО против реестра продаж: кто купил, кто нет, повторные (08.10.2026)

Создан 08.10.2026, проектная ветка «ПИШ». Записан по команде Марии «сохрани в репо выводы и ход работы». Ход работы — [hod-raboty/2026-10-08-zayavki-bio-i-reestr-prodazh.md](hod-raboty/2026-10-08-zayavki-bio-i-reestr-prodazh.md).

**Статус:** построения агента по двум источникам, командой не проверены. Счёт по таблице заявок — на глаз, не формулой: порядок верный, единицы могут плавать. Цифры из реестра — расчёт скриптом, точные.

Читались курс, даты, имя и комментарий менеджера. Остальные листы («Новые заявки ДПО», «Заявки сайт общие», «Лендинг ML» и др.) не открывались.
- **Реестр ДПО 2026** — файл xlsb от Марии (08.10.2026), лист «ПИШ»: 407 строк, 129 платных. Это тот же реестр, что в [prodazhi-dpo-do-2026-svodnye.md](prodazhi-dpo-do-2026-svodnye.md) (23.09), цифры не изменились; новое — фамилии и анкета слушателя. Лист «ЦИИ» (грант, паспортные данные) не использовался.
- Набор по датам — [2026-10-04-bio-nabor-po-dedlaynam.md](2026-10-04-bio-nabor-po-dedlaynam.md).

**Метод сверки:** платные слушатели БИО из реестра сопоставлены с заявками поимённо — по имени, фамилии, почте, курсу и времени. Сопоставление ручное. БИО = пайплайны, базы данных и генные сети, ML в биологии и медицине, продвинутые генные сети, геномная селекция, модули (Python, Linux, NextFlow, прикладной анализ).

- Результат в таблицу не пишется: покупателей в ней 63, пометок «оплачено» / «учится» по БИО меньше десяти. Статус — свободным текстом, у трети строк пусто. Источника заявки нет, кроме пары пометок «канал» и «вебинар». Даты есть только с августа 2025.

## 3. Кто купил (75 человек; анкета заполнена у 35)

- Работают 31 из 35; должность научная у 22: младшие, научные и старшие научные сотрудники, лаборанты, два доцента, врач.
- Работодатели — НИИ и вузы.
- Высшее образование почти у всех; студентов трое.
- Регион указан у 36: Москва и область — 11, Санкт-Петербург — 8, Саратовская область — 5, остальные по одному-два. Новосибирской области нет.
- Возраст в основном 23–45, медиана около 30; в колонке есть ошибки (3 и 126 лет).
- Итог обучения, физлица с известным статусом: закончили 15, не закончили 13. От организаций закончили все 20.

## 4. Кто не купил (около 100 заявок 2026 года, по комментариям менеджера)

Счёт причин — по всей таблице за два года, на глаз.

| Причина | Заявок |
|---|---|
| Не дозвонились («не взяла трубку, отправила письмо»); у половины есть телеграм | ~45 |
| Думали, что бесплатно | ~20 |
| Отложили на названный месяц («напомнить в августе») | ~18 |
| Хотели за счёт организации, не сложилось или не успели к потоку | ~17 |
| Не их курс (нет биологии, нужно продвинутое, не тот профиль) | ~10 |
| Дорого | ~8 |

- Заявок по «спецпредложению для студентов и сотрудников НГУ» около 17, оплат по этой цене видно две.
- Купившие и «хотел через организацию» — один сегмент; разница в сроке согласования.
- Про некупивших нет ни места работы, ни города: в заявке этих полей нет, реестр собирает их только после договора.

- Реестр считает по месяцу старта, таблица — по дате заявки; окна совпадают не строго.
- Около 25 строк таблицы без курса.
- Окно реестра — девять месяцев: купивший летом вернуться не успел.
- У селекции в реестре нет суммы — доля выручки повторных по БИО занижена.
- Первая оценка агента «покупает каждая вторая заявка» снята после поимённой сверки.
