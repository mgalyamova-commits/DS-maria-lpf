## Контекст

ПИШ — university-программа с несколькими параллельными треками (подтверждено структурой `pack/pish.md`, создан 13.09.2026 по итогам сборки годового отчёта):
- **ВО (высшее образование)** — приём в магистратуру: «Код доступа», ДОД, вебинары, тест-драйвы, два хакатона в год.
- **ДПО** — курсы для взрослых/юрлиц + «ДПО для ДО» (программы для педагогов): биоинформатика, геномная селекция, химия и новые материалы, ИИ в отраслях, геология и геофизика, космос.
- **ДО (допобразование школьников)** — секции (микроэлектроника, беспилотники, инженерный английский), инженерные каникулы, проектные смены, мастер-классы, экскурсии.
- **Сквозной/событийный блок** — представительские мероприятия (Технопром, Научный пикник, форумы), бренд, полиграфия, СМИ.
- **Интернет-блок** — 2 Telegram-канала («Передовая инженерная школа НГУ», детский «Инженерная лаборатория»), канал в MAX, Stepik, рассылки, посевы через подрядчика.

*(Предположение, не подтверждено дословно: ПИШ, вероятно — «Передовые инженерные школы», федеральная программа.)*

Регулярный формат: планёрка по понедельникам, большая команда. Существует также отдельный годовой отчёт-драйв — [pish/otchet-2025-2026.md](otchet-2025-2026.md) (черновик, редакция 8 на 13.09.2026) — не читан целиком в этой сессии, при следующей сверке контекста стоит заглянуть.
