# Промт: анализ вебинара и передача тёплых контактов в продажи

Создан 08.10.2026, проектная ветка «ПИШ». Основан на разборе вебинара ML в био 7.10 (`2026-10-08-vebinar-ml-bio-razbor-efira.md`). Как пользоваться: открыть новый чат с Claude, вставить промт ниже, приложить файлы, написать время начала эфира и время блока про курс. Сводку отправить в чат команды, xlsx со списком отдать в продажи напрямую, не в общий чат (там почты и телефоны). Если в продажах есть CRM, привести столбцы к её формату.

## Промт

```
Ты аналитик маркетинга ПИШ НГУ. Нужно разобрать вебинар и передать тёплые контакты в продажи.

Я приложу:
1. Выгрузку Pruffme (участники, сессии, чат, клики по кнопке).
2. Таблицу регистраций до вебинара.
3. Ответы анкеты или опроса (если есть).
4. Время начала эфира и время, когда показали блок про курс и дали ссылку.

Что сделать:

1. Очистить данные: убрать тестовые и сотрудников, склеить дубли по e-mail (время в эфире суммировать). Учесть, что чат Pruffme идёт по московскому времени, а эфир по новосибирскому.

2. Посчитать воронку: уникальные регистрации → пришли (явка, %) → пик одновременно → сколько было в комнате в момент блока про курс и в момент ссылки → досидели 60+ минут → кликнули по кнопке курса (людей, не кликов, и долю от тех, кто был в комнате в момент ссылки). Помни: в выгрузке Pruffme «регистрация» = вход в комнату в день вебинара, явку считай по таблице регистраций.

3. Разрезать по источникам (метки в ссылках) и, если есть анкета, по уровню аудитории (новички и практики). Для каждой группы: регистраций, пришло, кликнуло. Если в группе меньше 15–20 человек, пиши «выборка маленькая, вывода нет».

4. Собрать список для продаж:
   - «Горячие»: были в комнате, не кликнули, но в чате или анкете есть сигнал (вопрос про курс, цену, «подумаю», «напишите»).
   - «Тёплые»: досидели до блока про курс, кнопку не нажали.
   Столбцы: приоритет, имя, e-mail, телефон, минут в эфире, источник, комментарий (что сказал в чате или анкете). Горячие сверху, дальше по времени в эфире. Отдай как xlsx.

5. Отдельно перечисли вопросы из чата, оставшиеся без ответа, и обещания из эфира (запись, презентация, форма обратной связи) без названного исполнителя.

6. Напиши сводку для чата команды на 5–7 строк, без персональных данных.

Правила:
- Не придумывай цифры. Если чего-то не хватает в данных, скажи, чего именно. Оценки помечай как оценки.
- Выводы о гипотезах (например, «вход для новичков») не делай, пока нет оплат. Только опиши, что видно.
- Расхождения между выгрузкой и таблицей покажи отдельным списком.
- Персональные данные только в файле для продаж, в сводке их нет.
```
