# Архитектура проекта под нацпроект (Аналитик, 02.09.2026)

> Черновик показан Марии в чате 02.09.2026, сохранён по её подтверждению («сохрани презы отдельно и концепцию отдельно»). Источники: `koncepcia-immt-fo-2-0.md`, `2026-08-20-interview-berdsk-shkola-9.md`, `obsuzhdenie-strategii-i-granta-fpg.md`, `npt-prodolzhitelnaya-i-aktivnaya-zhizn.md`, `npt-novye-tehnologii-sberezheniya-zdorovya.md`.

## Entity of Concern
Архитектура школьного проекта «Паспорт здоровой школы», выстроенная так, чтобы явно закрывать мероприятие(-я) одного нацпроекта и одновременно удовлетворять интересы школы №9 и ИММТ НГУ.

## Bounded Context
Входит: выбор нацпроекта/ФП, покомпонентная архитектура, привязка каждого компонента к конкретному мероприятию ФП и к интересу конкретного стейкхолдера.
Не входит: пошаговый план выхода на ГВС/НМИЦ/Минздрав (следующий шаг по методичке «Медтех Навигатор», отдельная задача), юридическая проработка согласий, оценка шансов на грант ФПГ.

## Выбор нацпроекта

Из двух презентаций «Медтех Навигатор» релевантен один — **НП «Продолжительная и активная жизнь», ФП «Здоровье для каждого»**. Основания:

- Цель ФП — формирование системы укрепления общественного здоровья через новые подходы в профилактике ХНИЗ. Это дословно та же формулировка, что в миссии концепции проекта («профилактика хронических неинфекционных заболеваний»).
- Среди мероприятий ФП напрямую значится разработка рекомендаций по коррекции рационов питания **подростков** (отв. Роспотребнадзор) — прямое попадание в целевую группу проекта.
- Целевой показатель ФП — рост доли граждан, ведущих здоровый образ жизни, в 1,5 раза к 2030 году, с механизмом «индивидуальные программы ЗОЖ» через Центры здоровья для взрослых. **У ФП нет аналогичного мероприятия для школьников** — это белое пятно, которое проект может закрыть, а не продублировать чужую работу.

Второй нацпроект («Новые технологии сбережения здоровья») — про производство препаратов/изделий и медицинскую науку, не про профилактику среди населения. Прямого попадания нет; отмечен ниже только как вспомогательная, не основная линия для исследовательского слоя ИММТ.

## Архитектура (4 слоя, привязка к мероприятиям ФП и к интересам сторон)

**Слой 1 — Диагностика (Базовый уровень)**
Анкетирование, антропометрия, корректурная проба — как в концепции.
→ Мероприятие ФП: «изучение и коррекция рационов питания населения», «разработаны рекомендации по коррекции рационов питания подростков».
→ Интерес школы: наконец получает данные, которые сейчас видит только фельдшер/классный руководитель устно.
→ Интерес ИММТ: первичный массив данных для методологии.

**Слой 2 — Паспорт и рекомендации (школьный уровень)**
Паспорт школы с разделом «что с этим делать».
→ Мероприятие ФП: аналог «индивидуальных программ ЗОЖ», которые сейчас существуют только для взрослых через Центры здоровья — школа выступает тем же узлом для подростков.
→ Интерес школы: инструмент для управленческих решений (расписание, питание) — именно то, чего не хватает по словам Веры Викторовны.
→ Интерес Фонда «Образование»: закрывает давний внутренний вопрос «а что это даст» — рекомендации, а не сырые цифры.

**Слой 3 — Исследование (Продвинутый уровень, лаборатория ИММТ)**
Микробиота, биоимпеданс, углублённая методология — как во 2-3 «тёплых школах».
→ Прямого мероприятия в ФП «Здоровье для каждого» нет; это отдельная научная повестка ИММТ. Слабая, вторичная связь — с НП «Новые технологии сбережения здоровья», ФП «Управление медицинской наукой» (гипотеза, не подтверждённое соответствие — там финансируется медицинская наука в целом, не конкретно этот трек).
→ Интерес ИММТ: тот самый «крупный научный результат», которого им не хватало по итогам внутреннего обсуждения — публикации, доказательная база.

**Слой 4 — Конструктор и региональное тиражирование**
Методический протокол + шаблоны, передаваемые школам самостоятельно.
→ Мероприятие ФП: региональные программы по укреплению здоровья «в каждом муниципальном образовании» — сейчас это про взрослых, конструктор распространяет тот же принцип на школы региона.
→ Интерес школы №9: статус пилотной площадки, возможность обучать другие школы (прямо озвучено на интервью).
→ Интерес Фонда: закрывает найденную ранее проблему «нет большой рамки» — рамка теперь не абстрактная («нация» vs «воспитание»), а конкретное мероприятие конкретного ФП с измеримым показателем.

## Что не сходится и требует решения до подачи

- Слой 3 (исследовательский, самый важный для ИММТ) — единственный без прямой привязки к выбранному ФП. Если для ИММТ научный результат обязателен, придётся либо принять его как отдельную, не грантовую линию, либо отдельно прорабатывать соответствие по методичке «Медтех Навигатор» (мероприятие ↔ продукт) для НП №2.
- Тайминг гранта (ФПГ не раньше февраля 2027) по-прежнему не совпадает со сроками концепции (запуск осенью 2026) — архитектура эту проблему не решает, она из другого разговора.
