# Паспорт здоровой школы — описание предлагаемого проекта

> Черновик показан Марии в чате 02.09.2026, сохранён по её подтверждению («сохрани»). Синтез: `koncepcia-immt-fo-2-0.md`, `2026-08-20-interview-berdsk-shkola-9.md`, `obsuzhdenie-strategii-i-granta-fpg.md`, `arhitektura-proekta-pod-nacproekt.md`, `npt-prodolzhitelnaya-i-aktivnaya-zhizn.md`.

**Организаторы:** Фонд «Образование» (координация, связь со школами), ИММТ НГУ (научное руководство)
**Статус:** пилотный проект, 2026–2027 учебный год

## Обоснование

Проект встраивается в федеральный проект **«Здоровье для каждого»** национального проекта «Продолжительная и активная жизнь». Цель ФП — формирование системы укрепления общественного здоровья через новые подходы в профилактике хронических неинфекционных заболеваний; один из показателей — рост доли граждан, ведущих здоровый образ жизни, в 1,5 раза к 2030 году. Среди мероприятий ФП напрямую заявлена разработка рекомендаций по коррекции рационов питания подростков (отв. Роспотребнадзор) — у федерального проекта пока нет аналога школьного уровня для инструмента «индивидуальные программы ЗОЖ», который для взрослых реализуют Центры здоровья. Проект закрывает это белое пятно для школьников, а не дублирует существующий механизм.

## Цель

Дать школам инструмент самодиагностики физического состояния, питания и учебной активности учеников, который переводит собранные данные в конкретные управленческие решения, и одновременно вовлечь школьников в исследовательскую деятельность как соавторов, а не объект наблюдения.

## Целевые группы

Школьники 8–9 классов (исследователи, 4–6 человек от школы), их сверстники (пассивные участники, 30–40 человек параллели), кураторы (учитель + психолог + фельдшер + завуч по проектной деятельности), администрация школы, родители.

## Архитектура (4 слоя)

1. **Диагностика (Базовый уровень).** Анкетирование, антропометрия, корректурная проба на внимание — во всех школах-участницах.
2. **Паспорт и рекомендации.** Школа получает не сырые цифры, а раздел «что с этим делать»: конкретные шаги вроде переноса физкультуры или пересмотра меню.
3. **Исследование (Продвинутый уровень).** Микробиота, биоимпеданс — в 2–3 «тёплых школах» ИММТ, с участием школьников как исследователей.
4. **Конструктор и тиражирование.** Методический протокол, шаблоны анкет, видеоинструкции — передаются школам для самостоятельного ежегодного использования без внешней поддержки.

## Участники и роли

- **Школа (пример — СОШ №9 г. Бердска, 500 учеников, инклюзивная, два психолога, штатный фельдшер).** Даёт доступ к ученикам, кураторскую ячейку, площадку для конференции; ждёт доказательной базы для проектов учеников и конкретных управленческих рекомендаций.
- **ИММТ НГУ.** Научное руководство, обучение кураторов, лабораторный анализ продвинутого уровня; ждёт публикуемого научного результата.
- **Фонд «Образование».** Координация, коммуникация со школами, работа с родителями.

## Ожидаемые результаты

- Персонализированный «Паспорт здоровой школы» с рекомендациями для каждой школы-участницы.
- Первый сетевой массив данных о подростковом здоровье и образе жизни в регионе.
- Готовый «Конструктор самодиагностики», тиражируемый без организаторов.
- Реальный исследовательский опыт для школьников — собственные мини-проекты на итоговой конференции (апрель 2027).

## Открытые вопросы (не решены архитектурой, требуют отдельного решения)

- Финансирование: грант ФПГ не может стартовать раньше февраля 2027, а пилот планируется уже осенью 2026 — источник средств на переходный период не назван.
- Исследовательский слой ИММТ (продвинутый уровень) не имеет прямой привязки к выбранному ФП — если научный результат обязателен для ИММТ, это отдельная, не грантовая линия.
- Согласие родителей на биометрику/микробиоту — у школы уже есть опыт отказов на менее чувствительные процедуры, нужна отдельная работа с родителями, не сведённая к раздаче бумажки на собрании.
