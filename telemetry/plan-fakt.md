# План/факт по дням — Хаб

> **Что это.** Одна строка в день: что было запланировано и что получилось. Нужен, чтобы видеть прогресс по улучшению планирования. Создан 16.10.2026, решение Марии (ветка «Хаб»).
>
> **Кто пишет.** Только Хаб, `append` в конец. Старые строки не править. Дневник и другие ветки сюда не пишут. Фокус дня здесь не оценивается: вердикт ведёт Дневник (чекин, пункт 7), в строке только отсылка.
>
> **Когда.** По команде Марии «сведи день». Вечером не сводили — утром Хаб спрашивает за вчера одной строкой.
>
> **Откуда числа.** План — календарь дня плюс задачи портянки на этот день и просрочки с утра. Факт — слова Марии. Что она не подтвердила — в строке не считается закрытым.
>
> **Четыре числа для сравнения день ко дню:**
> 1. Задачи: план, закрыто, перенесено на дату, подвисло.
> 2. Просрочек с утра → подвисло к вечеру.
> 3. Встречи: прошли, сорвались не по Марии, пропущены Марией.
> 4. Блоки ДО/ПОСЛЕ: сделано из запланированного.
>
> **Недельная сводка** читает этот файл и сравнивает неделю с прошлой (блок «План/факт за неделю»).
>
> **Формат строки:** `ГГГГ-ММ-ДД | день | задачи: … | просрочек с утра N → подвисло к вечеру M | встречи: … | блоки ДО/ПОСЛЕ: x из y | фокус: см. чекин Дневника`
