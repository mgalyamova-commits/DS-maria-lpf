# Проходка чата — сообщение для вставки в проектный чат

> **Что это.** Текст разового сообщения, которое Мария вставляет в чат проектной ветки (или ветки «Финансы»), чтобы за один проход: выгрузить накопленные в чате файлы в `LPF-files/<slug>/` на Google Drive, собрать в одно место ссылки на Drive, записать «ход работы» чата в репо и получить заключение по `context.md`.
>
> Создано 03.10.2026 (IWE_Церен, `iwe-development/log.md`, Запись 11 → «Планируется», проход по вагону чатов). Версия 3: проверена Марией 03.10.2026 на старых ветках (Тандем, Химозин и далее) — работает, ничего не сломалось. Поправки по ходу теста: добавлена опись ссылок на Drive (шаг 3); подтверждённые файлы ветка выкладывает одним отдельным сообщением (шаг 7а).
>
> **Как пользоваться.** Вставить текст из блока ниже в чат целиком. В одном чате на проект — самом свежем — дописать в конце `+контекст`, иначе несколько чатов одного проекта несколько раз разберут один и тот же `context.md`. Хаб, Дневник и чаты обучения этой версией не покрыты: у них нет slug проекта.
>
> Постоянное правило для новых файлов — не здесь, а в `prompts/slot.md`, раздел «Файлы слота». Этот файл — для разбора уже накопленного.
