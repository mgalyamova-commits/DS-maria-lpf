# Описание фонда как системы (по методике курса «Распожаризация», R1.1:Tasks1)

Дата: 30.08.2026. Источник: трек обучения «Распожаризация», задание R1.1:Tasks1 — полная версия и разбор опор FPF лежат в [raspozharizaciya/r1-1-tasks1-opisanie-sistemy.md](../raspozharizaciya/r1-1-tasks1-opisanie-sistemy.md). Здесь — рабочая выжимка для проектного контекста ЦПИ/венчурного фонда.

## Система

Венчурный фонд deeptech-инвестиций: юридическое лицо с капиталом, органами управления (инвестиционный комитет), командой, портфелем проектов и процедурами отбора/сопровождения сделок.

## Ситуации эксплуатации

- Заявитель обращается с проектом → оценка.
- Инвестиционный комитет принимает решение о входе → договор.
- Портфельная компания выходит на транш/отчётность по контрольным точкам.
- Фонд на регулярном цикле мониторит портфель, корректирует план.
- Фонд при зрелости проекта выходит из него.

## Польза по ролям

- Частные инвесторы — финансовая доходность.
- НГУ — вывод результатов интеллектуальной деятельности на рынок.
- Государство/ФИОП — развитие deeptech-отрасли/технологический суверенитет (формулировка требует уточнения).
- Заявители/портфельные компании — финансирование + экспертное сопровождение.

## Создатели

- Учредители (решение + капитал): 3 частных инвестора, НГУ, государство (ФИОП).
- Исполнитель работы по созданию (Work): Мария — инициатор/управляющий партнёр, настраивающий воронку и процессы фонда.

## Действия по созданию

- Учредители: создание юрлица, утверждение правил, выделение капитала (разовые действия).
- Мария: настройка воронки отбора проектов, выстраивание процессов работы с портфельными компаниями (продолжающаяся операционная работа).
