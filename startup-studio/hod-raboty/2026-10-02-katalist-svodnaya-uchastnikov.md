# Ход работы: сводная участников Каталиста (бот, чат, Leader-ID, НГАУ)

Чат ветки «ЦПИ+УСС» (startup-studio), 30.09–02.10.2026. Проходка чата — 03.10.2026. Только факты из переписки.

## О чём чат

База участников осеннего акселератора Каталист: сведение выгрузок бота, Leader-ID и НГАУ в одну таблицу, её обновление по новым выгрузкам, выделение списка для email-рассылки.

## Задачи и решения

**30.09.2026 — сводная из трёх выгрузок.** Исходники: выгрузка бота на 29.09 (431 аккаунт), очищенная база Leader-ID (230 записей), участники из НГАУ (96). Решения:
- одна строка — один человек; аккаунты Telegram и MAX одного человека объединены;
- склейка бот ↔ Leader-ID по Leader ID, привязанному в боте (89), и по запросу Марии — дополнительно по ФИО при однозначном совпадении (10);
- НГАУ отмечается по номеру Leader-ID;
- вторым запросом добавлен флаг «В чате» (Да / Нет / Нет данных).
Итог — сводная на 555 человек, листы «Все», «Итоги», «Методика». На закрытии сессии предложены задача в портянку и запись в `katalist/context.md`; Мария: «ничего не пишем».

**01.10.2026 — мероприятие 606475.** Новых Leader ID относительно базы — 17 (9 из СибГУИБ), ни одного в боте. Сводная — 572 человека, флаги «606475» и «Новый с 606475».

**01.10.2026 — телефоны из бота.** Выгрузка бота с телефонами (427 аккаунтов, 189 номеров). Сопоставление по Telegram ID, MAX — по имени; внесено 187 номеров отдельной колонкой. Найдено: 14 новых Telegram-аккаунтов, 16 пропавших (среди них команда ЦПИ), 6 расхождений телефона бот ↔ Leader-ID. Сводная — 585 человек.

**02.10.2026 — обновлённая выгрузка 606475 (+11 заявок).** Решения Марии: колонку мероприятия назвать датой «02.10.2026»; «новые» — вариант А (не было в базе до мероприятия, нет в боте). Лист «Пуш на почту» — 25 человек для email-рассылки; Алмазова Т.Р. исключена (есть в боте под другим именем). Итог — финальная сводная, 595 человек.
