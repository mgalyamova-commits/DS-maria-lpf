# Ход работы: доклад «MVP для биотеха» для А:СТАРТ

Чат ветки «ЦПИ+УСС», 02–03.10.2026. Записан 03.10.2026 при разовой проходке чата.

## О чём был чат

Подготовка выступления на акселераторе А:СТАРТ для сайнс-трека: «MVP для биотеха — как проверять ранние гипотезы, когда продукта ещё нет».

## Какие задачи решались

1. Выборка по Pack и методам студии: что уже есть ценного по теме ранней проверки гипотез.
2. Разбор двух источников фактуры — транскрипт сессии 1 Астарты (8 проектов) и карточки 18 команд интенсива Хелснет; отбор тезисов под эту аудиторию.
3. Сборка спича на 30 минут, две переработки.
4. Сборка презентации на шаблоне Хелснета.
5. Оформление текста доклада по слайдам.
6. Запись выводов в репозиторий.

## Какие решения приняты и почему

- **Сквозной тезис:** без продукта проверяется не продукт, а утверждение, на котором всё держится; MVP в сайнс-треке — минимальная проверка самого рискованного утверждения, а не уменьшенный продукт. Выбран потому, что снимает основной блок аудитории «у нас нет продукта, нечего проверять».
- **Источники содержания:** ядро — `prompts/fpf-nauchny-proekt-gaidlayn.md`, усиления — `pack/startup-studio.md` и `pack/operacionnyj-menedzhment.md`. Терминология ФПФ со сцены не используется: для аудитории из лабораторий это шум.
- **Кейсы обезличены** — по правилу фильтрации публичной подачи из `pack/vystupleniya-i-meropriyatiya.md`: нерешённые споры по ИС и чужие неподтверждённые цифры со сцены не идут.
- **Добавлены положительные кейсы** (6 из 19 в промежуточной версии): первая сборка состояла только из провалов и читалась как порка.
- **Сокращено до 12 кейсов** и добавлен вводный блок про классическое MVP и три его условия — по требованию Марии.
- **Личный кейс на слайде 1** рассказывается своими словами, в текст не вносился.
- **Шаблон презентации** взят из файла Марии «Хелснет_выпускникам_интенсива_v3.pptx» — приём переиспользования визуального стиля мероприятия из уже присланного файла.
