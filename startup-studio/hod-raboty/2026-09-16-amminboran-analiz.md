# Амминборан (ИК СО РАН) — разбор и справка для команды

Дата последнего дня работы в чате: 16.09.2026.

## О чём был чат

Мария прислала пояснительную записку к заявке РНФ «Синтез и исследование пористых фотосенсибилизирующих материалов с иммобилизованным амминбораном для эффективной терапии раковых заболеваний» (ИК СО РАН, НТК «Гидридные соединения», к.х.н. Ольга Нецкина) и попросила анализ направлений коммерциализации.

## Какие задачи решались

Первый полный прогон метода ФПФ для научного проекта (Шаги 0–3): декомпозиция заявленных утверждений; проверка компетенций заявителя по открытым источникам (публикации, патенты, прежние проекты); поиск мирового конкурентного ландшафта по той же идее; разбор «генератор vs носитель» (где у заявителя реальный защищённый актив); формулировка нерешённой проблемы поля и гипотезы дифференциации команды; гипотетический альтернативный продукт (локальная платформа H₂ для ран вместо онкологии) с расчётом рынка и игроков; сборка читаемой справки для команды проекта без англицизмов, со ссылками на источники.

## Какие решения приняты и почему

Каждый раздел анализа добавлялся в рабочий файл только после отдельного Gate Марии — по разделам «компетенции», «конкурентный ландшафт», «генератор vs носитель», «нерешённая проблема поля», «гипотетический продукт», «игроки рынка». Справка для команды собрана и отправлена Нецкиной по прямому поручению Марии. Отдельно по итогам первого прогона метода внесены правки в сам файл метода (`prompts/fpf-nauchny-proekt-metod.md`) — зафиксированы слабые места, подтвердившиеся на практике (разведение Entity, проверка владения ИС — теперь n=3), и план дальнейшего тестирования.
