# Ход работы: продукты ЦПИ v2 — два образовательных курса для бизнеса

Чат ветки «ЦПИ+УСС», работа — 01.10.2026; разовая проходка чата — 03.10.2026. Только факты из переписки.

## О чём чат
Пересборка линейки продуктов ЦПИ: от v1 (13.09.2026, 4 продукта-кандидата) к v2 — два платных образовательных курса для бизнеса.

## Задачи и решения
1. Восстановлен контекст по v1 (`cpi-produkty-v1-kandidaty.md`). Транскрипт брейншторма команды сведён со стратсессией Союза выпускников. Решение Марии: два самостоятельных продукта — А «Навигатор корпоративных инноваций» и Б «НГУ для бизнеса» (рабочее); вебинар — прогрев на входе в А, а не отдельный продукт.
2. Б переведён из сервиса в образовательный курс; сопровождение «окно и человек» — внутри него.
3. А расширен на основные вузы НСО: методология одна, отдельный блок знакомства с вузами. НГАУ, НГТУ, СГУПС «точно в деле»; вузы заходят бесплатно ради лидов и распространяют курс среди партнёров; премиум А — межвузовская РГ.
4. Правила РГ на пилот выбраны Марией из вариантов агента: распределение по профилю, спорное решает НГУ; рамочное соглашение + прямые договоры, реестр у НГУ; деньги премиума — НГУ; отклик 5 дней, ведущий от НГУ.
5. Курс Горшкова «Открытые инновации» исключён из референсов (решение Марии).
6. Подача ректору сначала строилась на докладной о портфельной модели и ЦТП (Google Doc). После транскрипта встречи с ректором Мария отменила докладную как основу: концепт ректором не утверждён. Обоснование пересобрано на словах ректора со встречи (рыночное ДПО вместо показателей, ДПО как отдельный бизнес внутри вуза).
7. Б переписан по транскрипту рабочей сессии команды: 7 живых лекций, нулевой вебинар с документом для руководства участника, консультация → платное сопровождение, цена 150–200 тыс. руб. Решения Марии: закупки — в блок инфраструктуры, инновации — внутрь заказных задач, спорт и инфраструктура включаются сразу. По запросу Марии Б описан в трёх вариантах: для команды, для ректора, промо для партнёров.
8. Статус на закрытии сессии (решение Марии): первую гипотезу проверяем на Б; Б ждёт подтверждения Голубева, что он возьмётся; А отложен.
