# Регулярные напоминания — конфигурация

Источник истины для регулярных слотов. Любой агент (Claude, Hermes, Claude Code), у которого попросят "продлить напоминалки", должен прочитать эту таблицу и поставить новый батч через Telegram-бота (@aist_me_bot) на нужное количество дней вперёд.

## Слоты (время — локальное, часовой пояс UTC+7)

| Слот | Время (локальное) | Текст напоминания |
|---|---|---|
| Слот обучения | 07:30 | 📚 Слот обучения |
| Дело-лягушка | 09:00 | 🐸 Дело-лягушка — самая важная задача дня |
| Обед | 13:00 | 🍽 Обед |
| Перекус | 17:00 | 🥐 Перекус |
| Вечерний чекин | 20:30 | 🕗 Вечерний чекин: слот/обед/тренировка/ужин/состояние — разнести дневные заметки по местам |

## Правило пересчёта в UTC

Локальное время минус 7 часов = UTC (для передачи в `schedule_at`).

## Механика продления

1. Прочитать эту таблицу.
2. Уточнить у пользователя (если не указано) — на сколько дней вперёд ставить батч (по умолчанию 7).
3. Для каждого дня × каждого слота вызвать `send_telegram_message` с пересчитанным в UTC временем.
4. Ничего не менять в самой таблице без явного запроса пользователя на изменение состава/времени слотов.
