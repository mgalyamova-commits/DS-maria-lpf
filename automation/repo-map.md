# Карта репозитория DS-maria-lpf

Манифест структуры для любого агента (Claude, Hermes, Claude Code), работающего в этом репо. Обновляется при добавлении новых файлов/папок — правило: кто создаёт новый файл, тот обновляет и эту карту (и README — см. `automation/agent-workflow-rules.md`, раздел «Кандидаты»). Эта карта — только структура (что где лежит), без операционных правил — те живут в `automation/agent-workflow-rules.md`.

**Уточнение (01.09.2026):** этот файл может отставать от фактической структуры репозитория, если другая ветка создаёт файлы, не обновляя карту (см. пример — README уже знает про `pish/` и `startup-studio/context.md`, которых здесь пока нет). Актуальнее считать README для проектного слоя, если расхождение замечено.

## Pack — предметное знание доменов (с 05.09.2026)

## Автоматизация

- `automation/reminders-routine.md` — источник истины для регулярных Telegram-напоминаний (@aist_me_bot): слот обучения 07:30, дело-лягушка 09:00, обед 13:00, перекус 17:00, вечерний чекин 20:30 (локальное время, UTC+7 → минус 7 часов для schedule_at). Продление: пользователь говорит любому чату «продли напоминалки» — тот читает этот конфиг и ставит новый батч.
- `automation/agent-workflow-rules.md` — операционные правила поведения агента (когда что писать, куда, в каком порядке), включая процедуры проверки целостности, бэкапа и восстановления. Растёт по одному пункту за раз, с датой.
- `automation/repo-map.md` — этот файл.
- `automation/session-close-routing.md` — единый чек-лист роутинга при закрытии сессии (задачи/инсайты через Gate, сигналы о состоянии без Gate). Создан 05.09.2026.
- `automation/role-trials.md` — пилотирование новых ролей (гипотеза, критерий успеха/провала, дата сверки, вердикт на DRR). Активные пилоты с 05.09.2026: Верификатор, Экстрактор, Коуч (третья роль в ветке «Хаб+Дневник», не отдельный Project). С 05.09.2026 цикл пересмотра включает дополнительную линзу «экзоскелет vs протез». Создан 05.09.2026.

## Архитектура чатов (для контекста, не файл в репо)

Пользователь ведёт работу через Claude.ai Projects: «Хаб + Дневник» (новый чат на каждый день, с 05.09.2026 включает также роль «Коуч» третьей ролью в той же ветке), «Рабочие проекты» (один долгоживущий чат на проект), «Стартап-студия», «Обучение» (один чат на курс), «IWE совершенствование» (мета-работа над самой системой).
