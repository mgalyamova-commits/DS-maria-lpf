# Карта репозитория DS-maria-lpf

Манифест структуры для любого агента (Claude, Hermes, Claude Code), работающего в этом репо. Обновляется при добавлении новых файлов/папок — правило: кто создаёт новый файл, тот обновляет и эту карту (и README — см. `automation/agent-workflow-rules.md`, раздел «Кандидаты»). Эта карта — только структура (что где лежит), без операционных правил — те живут в `automation/agent-workflow-rules.md`.

## Регламент (обновлено 29.08.2026 — разбит на части)

- `docs/reglament/00-index.md` — оглавление LPF-регламента v2.6, начинать отсюда. Разбит на 9 частей 29.08.2026 (был единым файлом 700+ строк, инструменты чтения его усекали).
- `docs/reglament/01-arhitektura-cikl.md` … `09-pravila-drr.md` — сами части. Содержит именованные «Ситуации» (0–9, 11, 12) в части 5 (`05-situacii.md`) — пользователь описывает их через жизненный контекст, не называя номер напрямую; агент должен сам распознавать соответствие.
- `docs/lpf-reglament-v2.5.md` — старый путь, оставлен как редирект-заглушка на `docs/reglament/00-index.md`, не удалён (внешние ссылки).
- `docs/archive/lpf-reglament-v2.6-snapshot-2026-08-29.md` — архивный цельный снапшот перед разбиением, точка отката.
- `docs/drr-candidates.md` — сквозной список кандидатов в правки регламента между циклами DRR (часть 9 регламента, раздел 16). Пункт заносится сюда сразу при появлении в любом чате, а не только остаётся в дневнике дня — чтобы не потерялся к следующему DRR. Статусы: Candidate → Gate (принято) / остаётся кандидатом.

## Автоматизация

- `automation/reminders-routine.md` — источник истины для регулярных Telegram-напоминаний (@aist_me_bot): слот обучения 07:30, дело-лягушка 09:00, обед 13:00, перекус 17:00, вечерний чекин 20:30 (локальное время, UTC+7 → минус 7 часов для schedule_at). Продление: пользователь говорит любому чату «продли напоминалки» — тот читает этот конфиг и ставит новый батч.
- `automation/agent-workflow-rules.md` — операционные правила поведения агента (когда что писать, куда, в каком порядке), включая процедуры проверки целостности, бэкапа и восстановления. Растёт по одному пункту за раз, с датой.
- `automation/repo-map.md` — этот файл.

## Архитектура чатов (для контекста, не файл в репо)

Пользователь ведёт работу через Claude.ai Projects: «Хаб + Дневник» (новый чат на каждый день), «Рабочие проекты» (один долгоживущий чат на проект), «Стартап-студия», «Обучение» (один чат на курс), «IWE совершенствование» (мета-работа над самой системой). Любой новый чат должен быть в курсе структуры этого репо — для Claude это дублируется в памяти `/areas/lpf2-5.md`, для остальных агентов — источник истины эта карта и README.
