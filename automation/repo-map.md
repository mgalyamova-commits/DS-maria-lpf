# Карта репозитория DS-maria-lpf

Манифест структуры для любого агента (Claude, Hermes, Claude Code), работающего в этом репо. Обновляется при добавлении новых файлов/папок — правило: кто создаёт новый файл, тот обновляет и эту карту.

## Файлы

- `LPF-reglament.md` — полный регламент LPF v2.5. Содержит именованные «Ситуации» (0, 5, 8 и др.) — пользователь описывает их через жизненный контекст, не называя номер напрямую; агент должен сам распознавать соответствие.

## Телеметрия

**Правило (28.08.2026):** утреннюю телеметрию (сон/энергия/ёмкость) агент-Дневник заносит в `telemetry/history.md` и `telemetry/diary-2026-08.md` сразу по получении от пользователя в чате — не откладывая до вечера. Остальные поля (обед/ужин/тренировка/алкоголь/триггеры/эмоциональный фон) дозаполняются по ходу дня или на вечернем чекине, значение TBD до тех пор нормально.

- `telemetry/history.md` — ежедневный количественный лог (сон/энергия/ёмкость/тренировка/питание/алкоголь/триггер), по одной строке на дату
- `telemetry/diary-2026-08.md` — дневник-жилетка: качественные записи (эмоциональные триггеры, паттерны, кандидаты в правила), по одной секции на дату

## Обучение

- `learning/<slug>/progress.md` — прогресс по курсам МИМ, один файл на курс. Пока не заведено ни одного — появится с первым зафиксированным курсом (например, «Распожаризация» → `learning/firefighting/progress.md`).

## Автоматизация

- `automation/reminders-routine.md` — источник истины для регулярных Telegram-напоминаний (@aist_me_bot): слот обучения 07:30, дело-лягушка 09:00, обед 13:00, перекус 17:00, вечерний чекин 20:30 (локальное время, UTC+7 → минус 7 часов для schedule_at). Продление: пользователь говорит любому чату «продли напоминалки» — тот читает этот конфиг и ставит новый батч.
- `automation/repo-map.md` — этот файл.

## Планируется, ещё не создано

- `hub/portyanka.md` — активные/выполненные задачи по всем проектам, ведётся параллельно с гуглодоком-хабом на переходный период.

## Архитектура чатов (для контекста, не файл в репо)

Пользователь ведёт работу через Claude.ai Projects: «Хаб + Дневник» (новый чат на каждый день), «Рабочие проекты» (один долгоживущий чат на проект), «Стартап-студия», «Обучение» (один чат на курс). Любой новый чат должен быть в курсе структуры этого репо — для Claude это дублируется в памяти `/areas/lpf2-5.md`, для остальных агентов — источник истины эта карта.
