# Карта репозитория DS-maria-lpf

Манифест структуры для любого агента (Claude, Hermes, Claude Code), работающего в этом репо. Обновляется при добавлении новых файлов/папок — правило: кто создаёт новый файл, тот обновляет и эту карту (и README — см. `automation/agent-workflow-rules.md`, раздел «Кандидаты»). Эта карта — только структура (что где лежит), без операционных правил — те живут в `automation/agent-workflow-rules.md`.

**Досинхронизирован с README 13.09.2026** (ветка «IWE_Церен», по итогам разбора трения при правке README — см. `iwe-development/log.md`, Запись 6, и `automation/agent-workflow-rules.md` → кандидат от 13.09.2026, теперь GATE). С этой даты — **эта карта источник истины для построчного каталога файлов внутри проектов/папок**, README держит только одну строку на проект/раздел. Кто создаёт новый файл внутри уже существующей папки/проекта — добавляет ссылку сюда, не в README (README трогаем только когда рождается новый топ-уровень: новая ветка, новый проект, новая папка верхнего уровня).

## Автоматизация

- `automation/reminders-routine.md` — источник истины для регулярных Telegram-напоминаний (@aist_me_bot): слот обучения 07:30, дело-лягушка 09:00, обед 13:00, перекус 17:00, вечерний чекин 20:30 (локальное время, UTC+7 → минус 7 часов для schedule_at). Продление: пользователь говорит любому чату «продли напоминалки» — тот читает этот конфиг и ставит новый батч.
- `automation/agent-workflow-rules.md` — операционные правила поведения агента (когда что писать, куда, в каком порядке), включая процедуры проверки целостности, бэкапа и восстановления. Растёт по одному пункту за раз, с датой.
- `automation/repo-map.md` — этот файл.
- `automation/session-close-routing.md` — единый чек-лист роутинга при закрытии сессии (пять блоков с готовыми черновиками, явные триггерные фразы Марии), переработан 13.09.2026 из прежнего теста-опросника из 3 вопросов. С 14.09.2026 дополнен отдельным разделом «Факт прохождения сессии трека обучения» — независимо от Gate и от того, записан ли материал сессии, трек обучения пишет факт-строку в `telemetry/obuchenie-sessii-<месяц>.md`, чтобы Коуч мог закрывать привычку «Слот обучения» по файлу, а не только по устному отчёту.
- `automation/role-trials.md` — пилотирование новых ролей (гипотеза, критерий успеха/провала, дата сверки, вердикт на DRR). Активные пилоты с 05.09.2026: Верификатор, Экстрактор, Коуч (третья роль в ветке «Хаб+Дневник», не отдельный Project); с 11.09.2026 — Критик (цикл автор→критик→улучшение над текстами в проектных чатах, переключение персоны в том же чате). С 05.09.2026 цикл пересмотра включает дополнительную линзу «экзоскелет vs протез». Создан 05.09.2026.
