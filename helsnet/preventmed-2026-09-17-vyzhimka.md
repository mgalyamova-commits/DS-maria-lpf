## 1. Что Хелснет сказал публично

**Исследование с Purrweb (Мария + Соня):**
- Зрелость решения ≠ технологичность; зрелость = замкнутый маршрут «сигнал → действие → повторная оценка», с ответственным на каждом шаге.
- Проверяемого ROI программ здоровья нет: рынку нужно ~5 лет стабильности, горизонт оценки ~10 лет. Метрики (охват, выполнение рекомендаций, клиника до/после, больничные, финансы) доказывают каждая своё; данные лежат в разных отделах и почти не сводятся.
- Кейсы (данные НМИЦ ТПМ): сталевар (дистанционный мониторинг), НПЗ Оренбург (производственная медицина, снижение ВУТ), «ТМК без табака».
- Нацпроекты: миллиарды — туда, где понятны диагноз, маршрут и эффект в бюджетном цикле; превенции — сотни миллионов, и только на разработку, не на закупку.
- Инновации: >70% — госденьги; вуз доводит до УГТ 2–3, дальше дыра.
- Прогноз 2–3 года: быстрее всех растёт третичная профилактика (мониторинг хроников); Россия будет локализовать модель внедрения (кто платит, за что, кто отвечает), а не продукты.

**Резюме Марии на «Битве за compliance»:**
- Пирамида данные → инфраструктура → сервисы → действие; роль «того, кто ведёт маршрут и оценивает эффект разных маршрутов на длинном горизонте» на рынке не занята — не может жить внутри одной организации (у каждой свои метрики). Замкнутый контур есть только в ОМС, в ПМП.
- Предложение: договориться об общих метриках сравнения маршрутов/систем; закон Гудхарта как оговорка.
- Площадка — клуб «Цифровая медицина» (раз в месяц) → нормативные инициативы (ГОСТы, стандарты, рекомендации, приказы).

**Обещано со сцены (хвосты):**
- «Направим всем участникам материалы исследования» (пока — QR).
- «Делает ли кто-то в мире общие метрики — изучим».

**Андрианов (открытие):** «стартует взаимодействие» РНИМУ + Хелснет + Р-Фарм, надеется на продолжительное.

## 2. Зацепки для работы Хелснета

**Артёмова (советник ректора РНИМУ по ИИ, Альянс в сфере цифрового здравоохранения; «мама» ПМП)** — трёхшаговый трек:
1. НИР (на базе РНИМУ): форматы обмена и верификация данных мед- и немедизделий, метрология (Garmin/Whoop/Apple/российские).
2. ЭПР с учётом данных немедизделий для объективизации образа жизни.
3. Новая медуслуга в номенклатуре (+ порядок / КР), требования к протоколам для МИС/ГИС/платформы интернета вещей.
- Площадка — «РНИМУ или мероприятие НТИ»; технологический партнёр в идеале — Яндекс (Алиса).
- Опыт ЭПР по ПМП: инициатор Ростех (дочка), методцентры НМИЦ, разработчики, регионы; согласования Минздрав, ФСБ, ФСТЭК, РЗН, РКН, Минцифры, МЭР (в МЭР сменилось руководство профильного департамента).
- Боли ПМП: «кривизна» тарифа на дистанционное наблюдение; учитываются только данные медизделий, хотя платформа ИоТ принимает и немедицинские. Итог ПМП: ~30 тыс. пациентов, МР по АГ и СД, строка в подушевом, с 2025 — нацпроект «Продолжительная и активная жизнь».

**Зингерман (НБМЗ):**
- Публично назвал Марию инициатором публичного испытания редактора сценариев ДМ; в работе 15 новых сценариев, всего >200. Связь с задачей «Самойлов — ЮЛ на публичные испытания».
- Данные: Самара — группа со своим аптечным тонометром ×1,5 приверженности vs дорогой тонометр с автопередачей; зарегистрированные тонометры занижали давление. ПМП «до 300 тыс.» устройств vs ~6 млн тонометров в аптеках в год. ЦИТО: предгоспитальный мониторинг — отказы от госпитализации ↓ в 7 раз. Оренбург: 10 тыс. беременных, треть — 0 вопросов врачу, 1% — 150+. «7 привычек» (21 день после кардиологии): читали 75%.
- Тезис: ДМ нарезать на клинические сценарии; субъективные показатели (опросники) важнее «объективизации», особенно онкология между курсами; без врача люди бросают.
- Гильмутдинова анонсировала новую версию «Доктор ПМ» с Зингерманом как технологическим партнёром.

**Светлов (АМФП):**
- С Минздравом прорабатывают ЭПР по передаче данных пациентами (152-ФЗ, 323-ФЗ), обещает новости до конца 2026.
- Есть классификация цифровых сервисов + методика клинико-экономической оценки (ЦЭККМП + АМФП, статьи в «Медицинских технологиях» и «Фармакоэкономике», начало 2026); цель — «таблетка + цифровой компонент» в назначениях/КР. Институт-оценщик — ЦЭККМП.
- Рамка Марии: независимый «шильдик» для приложений по аналогии с ГИСП.

**Мишагина («Моторика», экс-ФСТ НТИ) — барьеры медстартапов:**
- ИИ-медизделие сразу 3-й класс риска; нет временных тарифов, тариф — по регионам.
- Интеграция в МИС/ЛИС клиники — от полугода и несколько млн ₽ на каждую; единых стандартов API нет.
- IP: медвуз не может отчуждать исключительную лицензию (особо ценное имущество), стратегам нужна исключительная.
- Долина смерти УГТ 3→6; фондов следующих стадий нет; вузовские датасеты не оцениваются как актив.
- B2C вытягивает только вхождение в экосистему.

**Дроздова (ГВС по медпрофилактике МЗ, НМИЦ ТПМ):**
- ФП «Здоровье для каждого» не включил цифровизацию наблюдения людей с факторами риска без заболеваний.
- После диспансеризации нечего рекомендовать для самоконтроля: нет медизделий, «маркетплейс» рекомендовать нельзя.
- НМИЦ ТПМ исследует «инфраструктуру здоровья» по регионам (точки продажи овощей vs алкоголь/табак) → данные для градостроительных решений.

**Стародубова (ГВС-диетолог ДЗМ):** нет открытой расширенной базы химсостава продуктов — блокер цифровой диетологии; цифровая диетология почти не медизделия; налоги на сахар эффекта на смертность не дали, перспективнее стимулы для ритейла.

**Медведев (MMC Pro, экс-«СОГАЗ Медицина»; медоператор «Газпром нефти», СИБУРа, «Транснефти» и др.):**

- ~60% компаний системно не занимаются здоровьем работников; классификация организационных моделей произв. медицины; BI «Цифровой спутник здоровья»; MMC+ (высокий ССР) — нужен человек-консультант; «цифровой профпатолог» с VK Tech.
- Открыто: классификации здоровья рабочей среды нет ни у кого.

**«Битва за compliance», прочее:**

- СберЗдоровье: пишут статью с Кобалавой (РУДН) по данным мониторинга — в КР нет, потому что нет российских публикаций.
