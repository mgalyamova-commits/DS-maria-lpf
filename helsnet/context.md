### Гипотезы: следующий шаг с Иннопрактикой

*Статус: гипотезы для обсуждения, не решения. Сформулированы 13.09.2026 по итогам сопоставления трёх материалов выше.*

**H1 — «Госпитальное исключение» как обход блокера ЭПР.** На сессии 18.06 зафиксирован блокер: полноценный ЭПР невозможен напрямую (61-ФЗ не отсылает к нему). Обзор PTDD даёт готовый обходной путь: госпитальное исключение для CAR-T уже разрешено в РФ и распространимо на мРНК/AAV-платформы **через подзаконный акт, без изменения закона**. Предложить эту логику координационному совету вместо продолжения поиска пути к ЭПР.

**H2 — Список для «протаскивания пилота» уже есть черновиком.** Пятый вывод сессии требовал собрать конкретный список компаний/технологий/нозологий. Таблица из обзора PTDD (Артген/Бетусфера, БИОКАД/MabNEXT+GeneNEXT, Генериум/AAV, НМИЦ гематологии/CAR-T, НМИЦ радиологии/неоантиген-мРНК) — фактически черновик этого списка. Следующий шаг — верифицировать его с компаниями и сузить до 2–3 кандидатов пилота, а не собирать заново.

**H3 — Формализовать участие Иннопрактики в Рамочном соглашении по ИИ.** Соглашение подписано в проекте как Хелснет + Р-Фарм + MS Decisions + AIRI. АНО «ИИЦ» (Иннопрактика) явно не названа стороной, хотя вступительное слово в отчёте написано от её имени (Олег Лавров). Уточнить и, при необходимости, оформить прямое присоединение АНО «ИИЦ» — это даст пилоту политический вес от самой Иннопрактики, не только от Р-Фарм.

**H4 — Свести две классификации платформ в одну таксономию.** На сессии обсуждалась классификация технологических платформ (доставка vs механизм действия) для критериев приоритизации; обзор PTDD даёт независимый список платформ по критериям FDA (AAV, мРНК, CAR-T, антитела). Сверить и предложить единую таксономию вместо двух параллельных документов.

**H5 — Один флагманский пилот вместо двух параллельных треков.** Платформа НМИЦ радиологии + партнёры (персонализированные неоантиген-мРНК-вакцины, «НЕООНКОВАК») одновременно демонстрирует и платформенную логику PTDD (единое технологическое ядро секвенирование → выбор неоантигенов → синтез мРНК → индивидуальный выпуск), и ИИ-логику Рамочного соглашения (выбор неоантигенов — задача, требующая валидации модели и мониторинга дрейфа). Предложить именно эту платформу как единый предъявляемый кейс для координационного совета вместо двух абстрактных треков.

**H6 — Общий состав рабочей группы, не общий документ.** Треки «ИИ-драгдизайн» (Рамочное соглашение → Совет по внедрению ИИ) и «платформенный статус» (обзор PTDD → рекомендации в Решение № 78 ЕАЭС) регулируют разные объекты (модель ИИ vs технологическая платформа) и адресованы разным органам (ТК 164/459 + Росстандарт vs ЕЭК) — сливать их в один документ не стоит, это размоет адресацию. Но у обоих треков одни и те же драйверы (Хелснет, Р-Фарм/Иннопрактика, AIRI) — предложить пересекающийся состав рабочей группы/Совета для синхронизации двух формально разных треков.
