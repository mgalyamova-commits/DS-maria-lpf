# Ход работы: НПТЛ-презентация к интенсиву НГУ (чат «Хелснет», 22.09.2026)

**Период:** одна сессия, 22.09.2026.
**Тема:** сборка презентации и текста выступления для мини-лекции Марии на интенсиве «От науки к бизнесу» (НГУ, направление «Технологии здоровья»), слот 10:30–10:45, день 1.

## Задачи

Собрать презентацию по двум нацпроектам технологического лидерства («Продолжительная и активная жизнь», «Новые технологии сбережения здоровья»), которые соответствуют профилям 21 команды интенсива, плюс текст выступления под 15-минутный регламент.

## Ход

1. Задача — презентация нацпроектов, подходящих профилям команд. Загружены карточки 21 команды (docx) и программа интенсива (Google Sheet со списком вопросов и логикой дня).
2. Составлен черновой мэтчинг команд по направлениям без привязки к конкретным ФП (на этапе, пока не было презентаций по самим нацпроектам).
3. Загружены две презентации по нацпроектам (ПАЖ — 11 ФП, НТСЗ — 5 ФП), референсная презентация логики/структуры с похожей программы («Новые материалы и химия»), презентация коллеги (Валиевой) по тому же интенсиву (взят визуальный стиль/брендинг НГУ), три PDF референсной программы в Альметьевске.
4. Собрана первая версия презентации: обзор обоих нацпроектов, метод поиска соответствия «продукт ↔ мероприятие ФП» (семантический анализ / декомпозиция инфраструктурных мероприятий / анализ нехлинических мероприятий), таблицы «команда ↔ ФП», алгоритм действий по типу продукта, блок мер поддержки, слайд с книгой ФИПС.
5. Несколько раундов правок по обратной связи:
   - в меры поддержки добавлены конкретные источники (взамен общих формулировок) по навигатору возможностей Хелснет НТИ (PDF с сайта): гранты, акселерация, инвестиции, партнёры экосистемы;
   - загружен и прочитан транскрипт сессии Минздрава по трансферу медицинских технологий; из него в алгоритм добавлены три гибких регуляторных режима (незарегистрированные ИВД, госпитальное исключение для клеточных продуктов, госпитальное исключение для био­тех/генотерапевтических индивидуальных препаратов) со ссылками на постановления, найденными в открытых источниках;
   - в таблицах «команда ↔ ФП» номера команд заменены на номер + короткое название из карточек;
   - в блоке мер поддержки оставлены в экосистеме только два пункта (Центр трансфера медицинских технологий Минздрава, ИЦ Хелснет НТИ) со ссылками на сайты — остальные категории (гранты, акселерация, инвестиции) сохранены как были;
   - добавлен отдельный слайд «Рекомендуем прочитать» (книга ФИПС) с кратким описанием содержания;
   - ссылки на книгу ФИПС и на обоих игроков экосистемы заменены на QR-коды (сгенерированы локально через LaTeX-пакет `qrcode`, т.к. сеть недоступна для pip/npm; код декодирован через OpenCV перед вставкой);
   - блоки «меры поддержки» и «рекомендуем прочитать» перенесены в конец презентации (после таблиц и алгоритма).
6. Отдельно составлен текст выступления (markdown) под хронометраж 15 минут, по структуре финальной презентации — не дословное чтение таблиц, только 2–3 примера вслух на раздел.
7. Разовая проходка чата (03.10.2026): составлена опись файлов и ссылок, по итогам — финальная презентация и презентация Валиевой переданы на Google Drive, текст выступления и транскрипт Минздрава записаны прямо в репозиторий.
