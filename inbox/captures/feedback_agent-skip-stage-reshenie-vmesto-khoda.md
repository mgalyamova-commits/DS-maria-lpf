# Feedback: агент выдал решения вместо ходов на этапе такта 1

**Симптом / контекст.** В ходе работы группы 3 на такте 1 кросс-вузовской экспертизы программы развития НГУ (07.10.2026) агент при фиксации семи разрывов по документам сразу сформулировал решения и шаги реализации, хотя этап требовал фиксации только постановки задачи и ходов группы.

**Корень / суть.** Агент без явного запроса продвигается на следующий этап работы (от хода к решению), что обгоняет темп группы и создаёт артефакт, не прошедший обсуждение на нужной стадии.

**Что нужно перестать делать.** Не формулировать решения и шаги реализации, если этап работы явно обозначен как «фиксация хода» / «постановка задачи».

**Что начать делать.** Перед выдачей содержания сверяться с заявленным этапом работы группы; если неясно, какой уровень детализации нужен — уточнять у пилота, а не выдавать максимально проработанный вариант по умолчанию.

**Где наступили / где заметили.** Сессия 07.10.2026, группа 3, такт 1. Реплика пилота: «мне не нужны решения, сейчас фиксируем ходы». Файл: startup-studio/hod-raboty/2026-10-07-kve-2-gruppa-takt1-chasti-1-2.md.
