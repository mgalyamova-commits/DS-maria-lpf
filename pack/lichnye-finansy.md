# Pack: Личные финансы

> Домен: анализ личных/семейных финансов по банковским выпискам — категоризация операций, разделение потоков и балансов, атрибуция дохода по источникам. Не входит: бухгалтерский/налоговый учёт, инвестиционный анализ.

## Скоуп домена

Работа с выгрузками из банковских приложений (Альфа-Банк и, вероятно, другие) для построения план=факт по доходам/расходам: как читать формат выписки, что в ней является сигналом, а что шумом, какие сущности типично смешивают при категоризации.

## Устойчивые факты

- Собственное поле «Категория» в банковской выписке (проверено на Альфа-Банке) малоинформативно — почти все операции по картам и переводам помечены общим «Прочие операции». Реальный сигнал для категоризации — MCC-код операции по карте (стабильный, кросс-банковский классификатор устройства/точки приёма) и текст описания QR/СБП-платежа (имя получателя, место).
- Переводы между своими же счетами в одной выписке (или в паре выписок по разным счетам одного человека) видны по совпадению номеров счетов в двух записях с одной датой (списание с одного счёта, зачисление на другой). Их нужно исключать из доходов/расходов целиком — иначе задвоение суммы.
- Автоматические сервисы «сбережения при зарплате» (у Альфа-Банка — «Копилка для зарплаты») в описании транзакции сбережения помечают исходный платёж именем плательщика в скобках. Это можно использовать для атрибуции дохода по работодателю, даже если сама строка зарплаты его не называет явно.
- Один работодатель может провести оплату одним днём несколькими отдельными транзакциями на счёт сотрудника (например, если у сотрудника несколько ставок/договоров с одним и тем же учреждением) — не путать несколько отдельных сумм от одного и того же плательщика в один день с несколькими разными источниками дохода.
- Не всякая сумма, поступающая на «сберегательный» по названию счёт, — реальное накопление: решает не название счёта, а то, тратятся ли эти деньги регулярно (по факту истории операций), или лежат нетронутыми.
- **«Справка о задолженности» — не то же самое, что «выписка по счёту» или «справка о движении средств».** Только справка о задолженности (запрашивается отдельно, обычно в приложении банка — раздел «Кредит»/«Документы») даёт полную картину кредита/кредитки разом: кредитный лимит, процентную ставку (в том числе разную по типам операций — покупки/наличные/минимальный платёж), график и размер минимального платежа, текущую задолженность на дату. Обычная выписка/справка о движении средств показывает только обороты за период — без лимита, ставки и баланса. Если нужны условия кредита, а не история операций по нему — запрашивать нужно именно справку о задолженности.
