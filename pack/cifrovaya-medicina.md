# Pack: Цифровая медицина / ИИ в медицине

> Создан 25.09.2026 из проектной ветки «Хелснет» (закрытие сессии, Блок 3, Gate Марии). Дополнен 30.09.2026 из проектной ветки «Инженерное образование» (закрытие сессии, Блок 3, Gate Марии). Дополнен 02.10.2026 из проектной ветки «Хелснет» (закрытие сессии, Блок 3, Gate Марии).

## Скоуп домена

Внедрение ИИ и работа с медицинскими данными в российском здравоохранении: данные, право, интероперабельность, регуляторика медизделий с ИИ, экономика внедрения, доверие врача. Не входит: фармрегуляторика лекарств (см. `pack/farmreguliatorika.md`), драгдизайн.

## Устойчивые факты

- Карта барьеров внедрения ИИ в российском медтехе (по обратной связи отрасли, 2026). Барьеры сцеплены: регуляторный тормоз в одном месте создаёт экономическую дыру в другом.
  1. Защита данных и избыточное обезличивание по 152-ФЗ — датасеты «обезличены» так, что на них нечему учиться. Направление решения: конфиденциальные вычисления (данные не покидают клинику).
  2. Право на данные — у держателей нет стимулов делиться, у ЕГИСЗ фактическая монополия на данные.
  3. Интероперабельность — плохо работающий реестр согласий, данные с носимых устройств в серой зоне.
  4. Классы риска — медизделие с ИИ почти автоматически получает 3-й класс, регистрация длинная и дорогая.
  5. Экономика — выводы предиктивной аналитики не встроены в клинреки и маршруты ОМС/ДМС, поэтому нет ROI, инвестор не видит, как на этом заработать.
  6. Доверие врача — генеративный ИИ принимается, если ответ проверяем и привязан к верифицированной базе знаний/клинрекам (мультиагентные системы + доверенные базы знаний).
- Оценка доступности медицинских данных для разработчиков ИИ — «5 из 10» (В. Светлов, рабочая группа по цифровизации здравоохранения АМФП, 2026).
- Граница медицины: медицина начинается там, где медработник на основании данных делает вывод. «Человек упал — сигнал бригадиру» — не медицина (Мария, 30.09.2026).
- Системы мониторинга состояния гибнут не на датчике, а на трении встраивания в существующую деятельность: персонал не сокращается, растут расходы на обслуживание самой системы, может понадобиться отдельный человек «на графики». Для алертов системы должны быть простыми: чем сложнее система, тем больше у неё собственных отказов и тем больше внимания она требует к своему обслуживанию (Мария, 30.09.2026).
- Электронная фиксация данных не снимает бумажную работу с медперсонала — аналогия: компьютеры у бухгалтеров не сократили бухгалтеров (Мария, 30.09.2026).
- «Кнопка жизни» для пожилых хорошо тиражировалась в России, но не окупилась (Мария, 30.09.2026).
- ИИ-софт медицинского назначения в России регистрируется Росздравнадзором как медицинское изделие и попадает в его реестр медизделий. Формулировка «одобрен Минздравом» для таких продуктов неверна; «создать реестр ИИ-продуктов» звучит для профильной аудитории как незнание рынка — реестр уже есть.
- Дистанционно ставить диагноз и назначать лечение можно только после очного приёма (правила телемедицины). Поэтому ИИ-помощник для пациента — информационный инструмент, а не замена врача; в публичных формулировках это стоит оговаривать.
